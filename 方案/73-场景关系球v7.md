# 73 · 场景关系球（v7）

> 用户的完整设计意图：
> 「非必要画个球形，我希望将这些节点排列成球，就是围绕一个或多个球体散开，
>  更有一种行星之间的美感」
> 「按重要性分层想法很好，但是大多都是场景之间的，这些并没有谁更重要这一说法」
> 「不要将技能、记忆这些做入节点，整个分支应该是由不同的场景互相做关联的」
> 「具体的场景其实可以做细分处理，比如说八字排盘和紫微斗数都算做一个场景，
>  但他们其实都是算做命理的节点」
> 「每个场景所对应的记忆、角色卡、技能、MCP 之类的，可以做成与对应场景节点交互的显示」
> 「这些场景节点我希望都可以支持拖拽，整个视图支持360°旋转上角加个整理即可」

## 二、关键 bug 与修复

### 2.1 节点不在球面上（实测抓到）

**症状：**
```
R = 279
dist 范围: 109 ~ 279
在球面上的节点: 2 / 10
→ 大多数节点在球内部，球体看起来"偏心"
```

**根因（我的多领域布局算法）：**
```js
centers = spherePositions(domains.length, R * 0.52)   // 小球心在 0.52R
subR = R * 0.42                                        // 小球半径 0.42R
→ 节点范围: 0.52R ± 0.42R = 0.10R ~ 0.94R
→ 球面上几乎没有节点
```

我本想做"多个小球环绕"，但把小球心放在主球**内部**，导致：
- 节点全在主球里
- 视觉上偏心、不均衡

**修法：所有节点直接铺在大球面的扇区**

```js
// 每个领域分配一个经度扇区，宽度 ∝ 场景数
for each domain:
  sector = { start, span ∝ count }
  for each node in domain:
    lon = sector.start + sector.span * (i+0.5)/n     // 经度均铺
    lat = -0.72 + 1.44 * (i+0.5)/n  (+交错微调)      // 纬度铺开
    pos = (cos(lon)*cos(lat)*R, sin(lat)*R, sin(lon)*cos(lat)*R)
```

**修复后：**
```
R = 158
dist 范围: 157.8 ~ 157.8
★ 在球面上的节点: 10 / 10  ✓
```

## 三、当前实现细节

### 3.1 数据层

```js
// 只加载场景（不含技能/记忆/项目）
scenes = rawScenes.filter(s => !s.isHub)

// 领域推断（按 role/name 关键词）
DOMAIN_RULES = [
  { mingli:  ['命理','八字','紫微','斗数','奇门','六爻','梅花','易经','占卜','风水','星相'] },
  { eng:     ['架构','实施','逆向','管线','工程','代码','部署','测试','性能','安全'] },
  { content: ['文档','内容','创作','视频','B站','图文','调研','竞品'] },
  { tool:    ['电脑','磁盘','清理','配置','环境','工具','维护'] },
  { social:  ['关系','情感','沟通','军师','复盘','自我'] },
]

// 边：从契约 outputs.to 建（真实依赖，不编造）
for each contract:
  for each output:
    for each target in output.to:
      if target 是场景 id: edges.push({ a, b, kind:'flow' })

// 兜底：若契约无 outputs，用同领域两两相连
```

### 3.2 布局层

```
单领域 → spherePositions(n, R)  [黄金角球面螺旋，最均匀]
多领域 → 按扇区分经度 + 纬度铺开   [同领域聚集，全部贴球面]
```

### 3.3 交互层

## 四、当前仍有问题（我需要继续优化）

### 4.1 视觉问题

```
① 节点太稀疏 —— 10 个节点撑不起球面
② 球体偏小 —— R = 158，面板宽 1170，只占 27%
③ 信息密度低 —— 大片空白
④ 没有"行星感" —— 用户说要的是行星之间的美感
```

### 4.2 我的思考（下一步）

**问题本质：10 个节点无法形成"球"的视觉印象。**

三条解法：

**① 放大球体** —— R 从 `min(W,H)*0.40` 提到 `min(W,H)*0.46`，让球占满面板

**② 节点视觉加重** —— 节点半径从 11 提到 14，光晕更强

**③ 「行星感」的真解：加轨道环**
用户说"行星之间的美感" —— 行星感的关键是**轨道**。
但用户又说"非必要画个球形" —— 所以不是画经纬网。

**我的折中方案**：不画球体轮廓，但画**领域轨道**（每个领域一条极淡的闭合轨道线）。
这是"行星轨道感"的来源，且不是球体轮廓。

```
命理 ────────┐
            │
工程 ──────┐ │
          │ │
内容 ───┐ │ │
       └─┴─┘
```

每条轨道是该领域节点的"聚集带"，极淡（8%~12% 透明度）。
