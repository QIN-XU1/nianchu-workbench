# 58 · 修复神经元交互崩溃

> 用户反馈：**"神经记忆元完全不可交互，一进行交互界面就会消失"**

---

## 一、根因（一行代码的致命错误）

### 1.1 崩溃代码

```javascript
let currentVisNodes = [], currentVisEdges = [];   // ← 声明为空数组

// 所有鼠标事件都是这样重绘的：
cv.addEventListener('mousemove', (e) => {
  if (dragging) {
    ...
    paint(currentVisNodes, currentVisEdges);   // ← 传空数组！
  }
});
cv.addEventListener('click', (e) => {
  ...
  paint(currentVisNodes, currentVisEdges);     // ← 传空数组！
});
```

### 1.2 后果

`currentVisNodes` **从未被赋值**，永远是空数组。

任何交互都调用 `paint([], [])` → 画布被清空 → **"一交互界面就消失"**。

### 1.3 为什么我写错

我原本想做一个"重绘封装"来记录当前可见集合：

```javascript
const origPaint = paint;
paint = function (vn, ve) {
  currentVisNodes = vn || currentVisNodes;   // ← 想在这里记录
  ...
};
```

但 **`function paint() {}` 是函数声明，不能用 `paint = ...` 重新赋值**（严格模式直接报 TypeError）。
我改成"在 paint 内部调用 paintStats"后就删掉了这段，**却忘了 `currentVisNodes` 从来没有被赋值这个事实**。

---

## 二、修复方案：单一状态源

### 2.1 架构重构

```javascript
const S = {
  allNodes: [],      // 全量节点
  allEdges: [],      // 全量边
  visNodes: [],      // 可见节点（过滤后）
  visEdges: [],      // 可见边
  byId: {},          // id → node 索引
  hover: null, sel: null, drag: null,
  panX: 0, panY: 0, zoom: 1,
  filter: '', panning: false,
  ready: false,
};
```

**关键改变：**

| 之前 | 现在 |
|---|---|
`paint(visNodes, visEdges)` 传参 | `render()` **无参**，永远从 `S.visNodes` 读 |
交互时直接改位置 + 传数组 | 交互只改 `S`，再调 `render()` |
`currentVisNodes` 空数组 | `S.visNodes` 由 `computeVisible()` 统一填充 |

### 2.2 三个单一入口

```javascript
computeVisible()   // 唯一：计算 visNodes/visEdges/结束时重建 byId
doLayout()         // 唯一：力导向布局
render()           // 唯一：绘制（含空数据保护）
```

### 2.3 空数据保护

```javascript
if (!S.visNodes.length) {
  ctx.fillStyle = C.text3;
  ctx.fillText(S.ready ? '（无节点）' : '加载中…', W / 2, H / 2);
  return;   // ← 不清屏，保留背景
}
```

### 2.4 防重复挂载

```javascript
if (body.dataset.neuronMounted === '1') {
  return function () { /* 已有实例，不重建 */ };
}
body.dataset.neuronMounted = '1';
```

之前日志里 `[neuron-yuxi] 32 节点 / 31 连线` 打印了 **4 次**，
说明渲染器被反复重建（切换场景时旧实例没清理干净）。
加挂载标记后只初始化一次。

## 五、教训

### 5.1 这是第五次同形错误

> **我的检查 ≠ 可信的检查**

之前我"验证"了神经元能用，只检查了：
- ✅ 渲染器已注册
- ✅ 数据加载成功（32 节点）
- ✅ 画布有内容（nonBlack > 0）

**但从没检查"交互后内容还在不在"。**

### 5.2 正确的验证方式

**要测交互，就必须真的派发鼠标事件，然后检查状态是否保持。**

```javascript
// 错：只看初始状态
console.log('canvas非黑像素:', nonBlack);

// 对：交互后再测
await 派发mousemove;
await 等500ms;
console.log('交互后 nonBlack:', 再测());   // ← 这才是判据
```

### 5.3 写进了代码注释

```javascript
/**
 * 【v3 的致命 bug】
 *   let currentVisNodes = []  ← 声明为空
 *   所有鼠标事件调用 paint(currentVisNodes, currentVisEdges)
 *   → 传空数组 → 画布被清空 → "一交互界面就消失"
 */
```

---

## 六、一句话

> **崩溃原因是一行代码：`let currentVisNodes = []` 声明后从未赋值，
> 所有交互都拿空数组重绘，等于每次点击都把画布擦干净。**
>
> **修法是架构级的：把"传参重绘"改成"单一状态源 + 无参 render()"。**
>
> **教训：我之前的验证只看了"初始能显示"，
> 没测"交互后还在不在" —— 这是第五次「我的检查 ≠ 可信的检查」。**
