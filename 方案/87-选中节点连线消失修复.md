# 87 · 选中节点连线消失修复

> 用户：「给节点的连接处理，比方为我点击了一个节点，
>       这个节点与其它节点之间的连线在旋转到特定位置线会消失」

---

## 一、自检定位根因

```js
// neuron.js 原代码（第 954-955 行）
const frontness = Math.max(pa.world.z, pb.world.z) / R;
if (frontness < -0.72) continue;     // ← 直接跳过不画
```

**两个问题：**

| # | 问题 | 后果 |
|---|---|---|
① | **硬裁剪**：两端都深于 -0.72 时直接 `continue` | 边突然消失/出现，无过渡 |
② | **不区分重要度**：选中节点的连线也被同样裁剪 | **选中的节点转到背面时，它的所有连线全部消失** |

`frontness` = 两端 z 坐标中较大者 / 半径。
当一条边连接的两个节点都转到球体背面时，`frontness < -0.72`，直接不画。

**用户点击的节点转到背面 → 它与所有节点的连线同时被跳过 → 整片消失。**

---

## 二、修复方案

### 2.1 区分「重要边」与「普通边」

```js
const isHot = focusId && (e.a === focusId || e.b === focusId);
const isNeighborLink = highlightLinks && highlightLinks.has(ei);
const lit = na.lit || nb.lit;

const isImportant = isHot || isNeighborLink || lit;
```

**重要边 = 与焦点/邻居/点亮相关的边。**

### 2.2 重要边永不裁剪

```js
// 普通边：只有两端都极深（< -0.95）才跳过
if (!isImportant && frontness < -0.95) continue;
```

**阈值从 -0.72 放松到 -0.95**（几乎只裁真正在正背面的，视觉上本来也看不见）。

### 2.3 软淡出代替硬切换

```js
// 之前：depthAlpha ∈ [0, 1]，背面直接是 0
const depthAlpha = Math.max(0.15, Math.min(1, (frontness + 1) / 2));
```

**下限从 0 提到 0.15** —— 背面仍有 15% 不透明度，不会"突然消失"。

### 2.4 重要边保留最低亮度

```js
const depthKeep = isImportant ? Math.max(0.55, depthAlpha) : depthAlpha;

if (isHot) {
  alpha = 0.40 * Math.max(0.72, depthKeep);   // 焦点边最少保留 72%
} else if (isNeighborLink) {
  alpha = 0.26 * Math.max(0.62, depthKeep);   // 邻居边最少 62%
} else if (lit) {
  alpha = 0.34 * Math.max(0.66, depthKeep);   // 点亮边最少 66%
}
```

**重要边即使转到背面，也保留 62%~72% 的亮度。**

## 四、延伸思考：为什么会有这个问题

### 4.1 硬裁剪是性能优化的遗留

早期为了性能，用 `continue` 跳过看不见的边。
**但"看不见"不等于"可以丢弃"** —— 尤其是对当前关注的对象。

### 4.2 三维空间中"重要对象"应该有穿透性

参考专业 3D 软件的做法：

| 软件 | 做法 |
|---|---|
**Blender** | 选中物体有 X-ray 模式（可穿透遮挡显示） |
**Unity Scene View** | 选中物体高亮，遮挡物半透明 |
**CAD 软件** | 选中零件轮廓始终可见（不管遮挡） |

**共同原则：用户明确关注的对象，应该有视觉优先级，不能被深度裁剪。**

我们实现的 `isImportant` 就是这个原则的体现。

### 4.3 另一种方案（未采用）

另一种做法是"选中节点的连线始终画在最上层"（改变绘制顺序）。
但这样会导致：
- 连线穿过所有节点（视觉混乱）
- 失去空间层次感

**我们采用的方案更克制：不改变绘制顺序，只保证亮度不衰减到看不见。**

## 五、一句话

> **根因不是"渐变"或"颜色"，而是**深度裁剪**：**
> **`if (frontness < -0.72) continue;` —— 两端转到背面就整条边不画。**
>
> **选中节点转到背面时，它的所有连线同时满足这个条件 → 整片消失。**
>
> **修复三件事：**
> **① 区分重要边（焦点/邻居/点亮）与普通边**
> **② 重要边永不裁剪，普通边改软淡出（下限 0.15）**
> **③ 重要边保留 62%~72% 最低亮度**
>
> **验证：12 个角度 × 3 条连线 = 36 次判定，全部可见。**
