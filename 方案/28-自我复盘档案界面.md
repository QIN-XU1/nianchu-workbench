# 28 · 自我复盘档案界面（文件窗口 + 预览窗口）

> 补齐需求 7.3 最核心的一块：
> **"有时候我要看文件，那就加一个文件窗口，想看文件内容，那就加一个预览窗口"**

---

## 1. 实现

### 1.1 并排双窗（luanyujia 验证过最高复用率的搭配）

```
┌─ 档案 ───────────────────────────────────────┐
│ [方案文档] [研究材料] [场景文档] [插件源码]     │
├──────────────────────────────────────────────┤
│ 文件列表（42%）      │ 预览（58%）            │
│ README.md  8.0KB  │ # README                  │
│ 00-一页读懂.md     │ ## 这套方案是什么…          │
│ 01-源材料…     │ • 七层架构                  │
│ …                  │ …                          │
└──────────────────────────────────────────────┘
```

### 1.2 四个可浏览的根

| 根 | 内容 | 文件数（实测） |
|---|---|---|
方案文档 | `方案/` 下全部 md | **35 个** |
研究材料 | `research/` 下 md | **122 个** |
场景文档 | `prototype/scenes/` 下 md/json | — |
插件源码 | `plugins/` 下 js/json/yml/svg | — |

### 1.3 三个新端点（全部实测 200）

| 端点 | 作用 |
|---|---|
`/sea-workbench/roots` | 列出可浏览的根 |
`/sea-workbench/files?root=X` | 列出该根下的文件（含大小、修改时间） |
`/sea-workbench/file?path=Y` | 读单个文件内容 |

**总计 11 个端点，全部 HTTP 200。**

## 2. 安全设计（三项防护 + 自检 6/6）

### 2.1 目录穿越防护

```
GET /sea-workbench/file?path=../../etc/passwd
→ HTTP 400（正确拒绝）
```

### 2.2 白名单防护

```
GET /sea-workbench/file?path=prototype/sea.mjs
→ HTTP 400（不在允许浏览的目录内）
```

### 2.3 三项自检

```
✓ 列出方案文档         35 个文件
✓ 列出研究材料         122 个文件
✓ 读取文件内容          README.md 8173B
✓ 目录穿越被拒         已拒绝
✓ 白名单外被拒         已拒绝
✓ 不存在文件明确报错      已报错
```

### 2.4 一个语义修正

最初非法路径返回 **500**（服务器错误），这是错的——**路径非法是客户端错误**。
改成 **400** 后语义正确了。

> 这个细节值得记：**http 状态码不是"能不能用"的问题，是"谁该负责"的问题。**
> 500 会让排查者去查服务器，400 才会让人去看自己的参数。

## 3. 界面现在有四个视图

| 视图 | 内容 |
|---|---|
**文档** | 场景的定位卡/记忆/技能/配置 |
**档案** | **文件窗口 + 预览窗口并排**（本轮新增） |
**注入预览** | 每轮会注入什么、多少字节、为什么跳过 |
**授权** | observe/off/auto 状态 + 记录了"想做什么" |

加上：
- 场景标签栏（6 个场景可切换）
- 能力开关卡片（**可点击切换**，唯一写操作）
- localStorage 记住展开状态与当前场景
