## 三、架构判断

### 3.1 依赖关系

```
DSH Harness（当前在跑）
  └── 引擎在 35935 端口，token 由 Harness 内部持有
            ↑
            │  需要 token + port
            │
工作台（Electron）
  └── 3D 星盘 + 9 场景 + 面板
```

**工作台本身不产生引擎，它复用外部引擎。**

harness.log 已经明确说了：
```
[engine] 修复建议:
  · 应让 DeepSeek Harness 主程序拉起引擎，然后通过 DSH_ENGINE_TOKEN 传入。
```

### 3.2 三种可选方案

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
**A. 插件拉工作台 + 传 token** | 插件用 `ctx.connection.authenticatedUrl()` 拿 token，spawn 工作台并传环境变量 | 一套引擎，数据互通 | 需要 spawn 外部进程 |
**B. 纯跳转（打开本地 URL）** | 工作台跑起来后监听一个本地端口，插件里 `<a href>` 跳过去 | 最简单 | 工作台没跑时点不动 |
**C. 双进程并存** | 工作台自己起独立引擎 | 互不干扰 | 两套引擎，数据分离，吃内存 |

**我选 A**：一套引擎、数据互通、符合用户「跳转到之前那个项目」的意图。

## 四、方案 A 的具体设计

### 4.1 插件提供什么

```
侧边栏入口「工作台」→ 主面板显示启动页
                        ├── 状态：工作台未启动 / 已启动
                        ├── [启动工作台] 按钮
                        └── 启动后显示「已打开」+ 窗口信息
```

### 4.2 启动时做什么

```js
// Host 侧
const connection = ctx.get('connection');
const engineUrl = connection.authenticatedUrl('http://127.0.0.1:PORT');
// → http://127.0.0.1:PORT/?token=xxx

// 解析出 token 和 port
const u = new URL(engineUrl);
const token = u.searchParams.get('token');
const port = u.port;

// spawn 工作台
const child = spawn(workbenchElectron, ['.', '--disable-gpu', ...], {
  cwd: workbenchShellDir,
  env: {
    ...process.env,
    DSH_ENGINE_TOKEN: token,     // ← 关键
    DSH_PORT: port,              // ← 关键
    DSH_FRONTEND: 'v2',          // 用新前端
    ELECTRON_RUN_AS_NODE: '',    // 必须清空
  },
  detached: true,
  stdio: 'ignore',
});
```

### 4.3 关键参数（从之前的调试经验）

| 参数 | 值 | 为什么 |
|---|---|---|
`DSH_ENGINE_TOKEN` | 从 `authenticatedUrl` 解析 | 工作台靠它调引擎 |
`DSH_PORT` | 同上 | 引擎端口 |
`DSH_FRONTEND` | `v2` | 不设会用旧前端 |
`ELECTRON_RUN_AS_NODE` | **必须清空** | 否则 electron 以纯 Node 运行，起不来窗口 |
`--disable-gpu` 等 | 保留 | 本机 GPU 有问题 |

### 4.4 端口怎么拿

`ctx.webServer.getOrigin()` → `http://127.0.0.1:35935`
（`webServer` 服务之前已确认存在）

## 七、与已有的 127 项插件测试的关系

现有的 `memory-neuron` 插件（分层星图 + 运营面板）**要不要留？**

我的判断：**留，但改名**。
- 它提供的是「场景运营数据视图」（台账、健康度、场地地图）
- 工作台提供的是「3D 星盘 + 场景操作」

两者互补，不冲突。

**新的插件包结构**：
```
plugins/
├── memory-neuron/     ← 保留：运营数据视图（127 项测试）
└── workbench-launcher/ ← 新增：启动 Electron 工作台
```

## 八、一句话

> **在 DSH 侧边栏加一个「工作台」入口，点击后拉起那个 Electron 项目，
> 并把当前 DSH 引擎的 token + 端口传给它，让两套系统共用一个引擎。**
>
> **不是在 DSH 里重建面板，而是给它开一扇通往老项目的门。**
