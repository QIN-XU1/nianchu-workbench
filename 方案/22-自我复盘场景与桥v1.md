## 1. 自我复盘场景（已建成，且真的在查真问题）

### 1.1 形态

| 项 | 内容 |
|---|---|
场景 id | `self-review` |
职责 | 保证自己的档案都有索引、索引不指向不存在的档案、档案名不重复 |
不碰 | 不改档案正文、不替人下结论 |
真实数据 | **31 份档案**（本项目 28 篇方案 + 3 份深读报告） |
判定 | `check.mjs`（exit 0 = 通过；非 0 = 差异集合 + 每项可定位） |

### 1.2 它抓到过真实问题

第一次跑，它报出：

```
sea · 1 件事需要你
  FAIL 自我复盘  自己的档案必须有索引；索引不得指向不存在的档案；档案名不得重复
       差 未登记的档案 2(research/deep-superagent.md, research/deep-vcp.md)
```

**这两份是我刚写的深读报告，确实没登记进索引。** 补登后变绿。

### 1.3 门禁认证

```
ACCEPT  check.mjs  (self-review)
  G1 基线通过        : true
  G2 变异全捕获      : true (3/3)
  G3 失败带差异集合  : true
  G0 已声明不变量    : true
  G0.5 达到不变量下限 : true
```

### 1.4 下半场：它先抓到了我自己的缺陷

建场景时，我把 `protects` 写成 `['completeness', 'uniqueness']`，结果**门禁自己拒了它**：

```
G0.5 失败：不变量声明过弱 —— required-field(存在必填型字段（如 name/owner/status），必须保护非空)
```

因为档案里有 `name` 字段。补上 `required-field` + 对应的 check 逻辑后通过。

> **这是"下限规则抓到我自己的疏忽"的真实例子**，比任何演示都有说服力。

### 1.5 与 luanyujia 的 self-review 对比

| 项 | luanyujia | 我们 |
|---|---|---|
形态 | 4 面板（预览/库/DeepSeek网页版/AI） | **有可检验的 check** |
职责 | 浏览 `<DSH根>\自我复盘` 的文件 | 保证档案索引完整 |
优势 | 界面丰富 | **可自动验证、能量化** |
缺口 | 无自动验收 | 无多面板界面 |

> 我们的形态更窄，但**它每次都能证明自己是对的**——这是 luanyujia 的 self-review 做不到的。

## 2. 桥 v1：DeepSeek 网页版（链路已打通）

### 2.1 零依赖实现

本机没有 puppeteer / playwright，但发现两个条件都满足：
- **Node 24 内置 WebSocket**
- **Chrome 156 支持 CDP**（Chrome DevTools Protocol）

所以桥是**零依赖**的：只用 `fetch` + 内置 `WebSocket`。

```
bridge/
├── sites.json    站点薄壳（照抄 luanyujia：inputSel/quietMs/knownIssues）
├── cdp.mjs       极简 CDP 客户端（连接/求值/关闭）
└── bridge.mjs    一步问答：机密闸 → 探测 → 找页 → 输入 → 发送 → 两步等待 → 提取
```

### 2.2 三条自检（luanyujia 明确要求的）

```
桥自检
  ✓ 未就绪时明确报错（不返回空串）  code=NOT_LOGGED_IN
    msg=DeepSeek 网页版 页面没有输入框 —— 多半是没登录。请在那个窗口手动登录一次。
  ✓ 机密闸拦截密码  拦截类型=密码/口令
  ✓ 普通文本不被误拦  放行
```

**exit=0，无崩溃。**

### 2.3 真实链路验证（做到了哪一步）

| 步骤 | 实测 |
|---|---|
探测 Chrome 调试端口 | ✅ `✓ Chrome 可连：Chrome/156.0.8078.80` |
列出标签页 | ✅ 正确列出所有页面 |
导航到 DeepSeek | ✅ `Page.navigate` 成功，落地 `https://chat.deepseek.com/sign_in` |
识别未登录 | ✅ `code=NOT_LOGGED_IN`，明确说"没有输入框" |
**机密闸** | ✅ 密码/token/身份证/银行卡/手机号 5 类拦截 |
**提问并取回答案** | ⏳ **未验证**（需要你手动登录一次） |

### 2.4 必须你手动做一步

桥**不做自动登录**（这是 luanyujia 的硬规矩：自动登录必触发风控）。

请在那个已打开的 Chrome 窗口里**手动登录 DeepSeek**，然后跑：

```powershell
cd "D:\file\AI Temp\DeepSeek\Agent自研"
node prototype\bridge\bridge.mjs ask deepseek "用一句话解释什么是闭包"
```

我已经帮你启动了带调试端口的 Chrome（独立 profile，不影响你日常浏览器）：

```powershell
& "$env:LOCALAPPDATA\Google\Chrome\Application\chrome.exe" `
  --remote-debugging-port=9222 `
  --user-data-dir="$PWD\prototype\bridge\.profiles\deepseek"
```

### 2.5 照抄的五个真实坑（来自 luanyujia 源码注释）

| 坑 | 我们的处理 |
|---|---|
豆包纯文字 45~60s | 薄壳里按站设 `quietMs`，DeepSeek 设 20s + 硬超时 120s |
DeepSeek 最新消息在最上面 | 用"公共前缀"切分，不依赖 DOM 顺序 |
会渲染"已思考（用时 N 秒）" | 正则切掉 `已思考[（(]用时\s*\d+\s*秒[）)]` |
发送键是纯 SVG | 先试回车，失败后按**几何位置**点输入框右下角 |
必须真实用户聚焦 | 输入前 `el.focus()` + `el.click()` |
