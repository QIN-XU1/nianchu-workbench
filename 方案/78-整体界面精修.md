### 2.2 关键设计原则

```
① 深空底 + 微弱层次（不是纯黑，也不是灰）
② 边框极细（1px，低透明度），靠留白分隔而非线条
③ 标题栏要"薄"，减少压迫
④ 数字/标签用等宽字体，有科技感
⑤ 强调色克制（只在关键处用藤黄/石青）
⑥ 所有圆角统一（2px），不做大圆角
```

## 四、Bloom 泛光实现（这是本轮最大技术收获）

之前完全没有 Bloom —— 这是「科技感」的核心技术缺失。

### 4.1 原理

```
① 降采样到 1/4（天然模糊）
② 再降到 1/8（更宽的光晕）
③ 用 'lighter' 混合叠加回主画布
```

### 4.2 踩过的坑

```js
// ❌ 错误（第一次）
c2d.drawImage(S.bloomCanvas, 0, 0, W, H);
// W/H 是 CSS 尺寸，但主画布是 W*DPR × H*DPR
// → 只覆盖左上角 1/DPR → 画面出现矩形色块边界

// ✅ 正确
const PW = cv.width, PH = cv.height;   // 物理像素
c2d.drawImage(S.bloomCanvas, 0, 0, w4, h4, 0, 0, PW, PH);
```

### 4.3 效果

```
最大亮度: 201/255 → 255/255   ← Bloom 生效
```

## 五、空间分布修复

```
问题: 画布占用 水平 54%, 垂直 28%（节点挤在中上部）

根因: lat = (rnd-0.5)*1.8 → sin(±0.9)=±0.78
      distF 平均 0.5
      → 实际 y 只占 RY 的 0.78 × 0.5 ≈ 39%

修法: 立方体内均匀采样（拒绝采样保证球内均匀）
结果: 垂直 28% → 72%
```
