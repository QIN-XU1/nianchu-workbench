## 二、官方参数推翻了我的做法

### 2.1 Bloom 官方源码（bloom-example）

```js
graph.backgroundColor('#000003')       // ★ 近乎纯黑
bloomPass.strength  = 4                // ★ 强度 4
bloomPass.radius    = 1
bloomPass.threshold = 0
```

**对比我的做法：**

| 参数 | 官方 | 我之前的 | 错误程度 |
|---|---|---|---|
backgroundColor | **#000003** | #060A16 | 亮了约 20 倍 |
Bloom strength | **4** | 0.42 | 弱了 10 倍 |
threshold | **0** | 未设 | 无控制 |

**这就是我审美错误的根源：**
- 我怕"死黑"，把背景提亮 → 画面发灰，失去深邃
- 我把 Bloom 做得极弱 → 节点不发光

**官方做法：背景近乎纯黑 + Bloom 极强 = 深邃 + 发光。**

### 2.2 高亮邻居网络（highlight-example）★ 最重要

```js
// 悬停时收集：自己 + 邻居 + 相关边
node.neighbors.forEach(n => highlightNodes.add(n));
node.links.forEach(l => highlightLinks.add(l));

// 三色分层
hoverNode  → 'rgb(255,0,0,1)'        红（最亮）
neighbor   → 'rgba(255,160,0,0.8)'   橙
other      → 'rgba(0,255,255,0.6)'   青

// 边宽：高亮 4，普通 1
.linkWidth(link => highlightLinks.has(link) ? 4 : 1)

// 粒子：高亮 4 个，普通 0
.linkDirectionalParticles(link => highlightLinks.has(link) ? 4 : 0)
```

**这个「悬停高亮邻居网络」我完全没有。**
之前悬停只是节点自己变亮，**看不出它跟谁相连**。

### 2.3 粒子参数（particles-example）

```js
.linkDirectionalParticles("value")                    // 粒子数由数据决定
.linkDirectionalParticleSpeed(d => d.value * 0.001)  // 速度也由数据决定
```

**粒子应该表达"关系强度"，不是固定值。**

## 四、踩到的坑

### 4.1 误删 applyBloom

删除 `drawNebula` 时，因为两个函数相邻，`applyBloom` 也被一起删掉了。
结果页面报错：**`applyBloom is not defined`**。

**教训：删除函数时要用精确的边界检测，不能靠"往前找注释开头"。**

### 4.2 节点状态变量顺序错误

`isDimmed` 在第 835 行被使用，但定义在第 842 行之后 → `Cannot access before initialization`。

**修法：把所有状态变量计算统一提到透明度计算之前。**

### 4.3 Bloom 强度不能照搬

官方 strength = 4 是 ThreeJS 的 UnrealBloomPass。
Canvas 2D 的"降采样叠加"实现，强度 1.2 就已经接近过曝。
**照搬 4 会全白。**
