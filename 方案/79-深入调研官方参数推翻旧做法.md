## 一、调研结论：我之前的审美参数几乎全错

### 1.1 官方 3d-force-graph 的 Bloom 参数（真实源码）

```js
// 来源：example/bloom-effect/index.html（已抓取存档）
graph.backgroundColor('#000003')      // ★ 几乎纯黑！不是 #060A16
bloomPass.strength  = 4               // ★ 强度 4！我用的 0.42
bloomPass.radius    = 1
bloomPass.threshold = 0               // 全画面发光
```

**对比我的做法：**

| 参数 | 官方 | 我的 | 差距 |
|---|---|---|---|
backgroundColor | **#000003** | #060A16 | 我的亮了 20 倍 |
Bloom strength | **4** | 0.42 | 我的弱了 10 倍 |
Bloom threshold | **0** | （未设） | 无阈值控制 |

**这就是我审美错误的根源：**
- 我把背景"提亮"了（怕死黑），结果画面发灰
- 我把 Bloom 做得极弱，结果节点不发光

**官方做法：背景接近纯黑 + Bloom 极强 = 深邃 + 发光。**

### 1.2 官方高亮模式（highlight-example 源码）

```js
// 悬停时：高亮节点 + 邻居 + 相关边
node.neighbors.forEach(n => highlightNodes.add(n));
node.links.forEach(l => highlightLinks.add(l));

// 颜色分层（精髓）
hoverNode    → 'rgb(255,0,0,1)'        红（最亮）
neighbor     → 'rgba(255,160,0,0.8)'   橙
other        → 'rgba(0,255,255,0.6)'   青

// 边宽：高亮 4，普通 1
.linkWidth(link => highlightLinks.has(link) ? 4 : 1)

// 粒子：高亮 4 个，普通 0
.linkDirectionalParticles(link => highlightLinks.has(link) ? 4 : 0)
```

**这个「悬停高亮邻居网络」我完全没有。**
现在只是节点自己变亮，但**它跟谁相连看不出来**。

### 1.3 粒子示例

```js
.linkDirectionalParticles("value")               // 粒子数由数据决定
.linkDirectionalParticleSpeed(d => d.value * 0.001)  // 速度也由数据决定
```

**粒子密度/速度应该表达"关系强度"，不是固定值。**

### 1.4 拖拽固定

```js
.onNodeDragEnd(node => {
  node.fx = node.x; node.fy = node.y; node.fz = node.z;  // 固定位置
});
```

## 二、用户说"不喜欢星云和球体"—— 我要换什么

### 2.1 星云的问题

```
我做的是：3 团大范围柔光斑
视觉效果：像脏污渍 / 像雾，掩盖了星空
用户感受：不喜欢
```

**星云这个方向本身就不对。** 真实的深空不需要"彩色雾团"，
只需要：**纯黑背景 + 密集星点 + 少量高亮天体**。

### 2.2 球体的问题

```
我做的是：节点排成椭球、有球体光晕
视觉效果：像地球仪 / 像玻璃球
用户感受：不喜欢
```

**"球形"限制了我的思路。** 用户真正要的是"宇宙分布"——
星星不是在球面上，是在**无边的空间**里。

### 2.3 正确的方向（综合官方做法）

```
① 背景 #000003（近乎纯黑，深邃）
② Bloom strength 4（强泛光，真正的发光感）
③ 星星分布：**无边界体积分布**（不提"球"，只提"空间"）
④ 不要星云雾团
⑤ 悬停高亮邻居网络（红-橙-青三色分层）
⑥ 粒子表达关系强度
```
