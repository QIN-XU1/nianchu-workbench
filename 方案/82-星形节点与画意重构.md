## 一、① 节点改为 ✦ 真星形

### 1.1 之前：一个圈 + 几条线

```js
// 旧实现
c2d.arc(pr.sx, pr.sy, coreR, 0, TAU);    // 画圆
c2d.moveTo(...); c2d.lineTo(...);        // 画 4 条直线
```

**视觉：圆点 + 十字线，确实就是“一个圈几条线”。**

### 1.2 现在：真四角星（贝塞尔凹边）

```js
function traceStar4(x, y, R, concave) {
  const cr = R * concave;      // 凹点半径
  // 上尖 → 右尖（控制点在右上凹点 315°）
  c2d.moveTo(px(270, R), py(270, R));
  c2d.quadraticCurveTo(px(315, cr), py(315, cr), px(0, R), py(0, R));
  // 右尖 → 下尖（控制点 45°）
  c2d.quadraticCurveTo(px(45, cr), py(45, cr), px(90, R), py(90, R));
  // 下尖 → 左尖（控制点 135°）
  c2d.quadraticCurveTo(px(135, cr), py(135, cr), px(180, R), py(180, R));
  // 左尖 → 上尖（控制点 225°）
  c2d.quadraticCurveTo(px(225, cr), py(225, cr), px(270, R), py(270, R));
}
```

**关键：4 个尖角 + 4 个平滑内凹的贝塞尔边 = 真正的 ✦**

参数经过自检调整：
```
凹点比    0.20 → 0.26（更饱满，不过于瘦长）
星形半径  1.12 → 1.02（配合饱满凹点）
```

### 1.3 三层结构

```
① 外柔光    径向渐变（不是环形线）
② ✦ 星形体  实心填充 + 极细描边
③ 核心亮点  小径向渐变（过曝质感）
```

## 二、② 高亮线“断断续续”的真实原因

### 2.1 我一开始判断错了

我以为是**渐变色两端太淡**，于是把两端 alpha 从 0.30 提到 0.72。结果**仍然断**。

### 2.2 放大截图后找到真因

**星形填充是半透明的**，连线从星形中间穿过，透了出来，形成“断裂的效果”。

```js
// 双重淡化
c2d.globalAlpha = alpha;          // 深度控制（0.26~1.0）
c2d.fillStyle = hexA(color, 0.58); // ← 又叠一层 58% 透明
// 实际不透明度 ≈ 0.15~0.58 → 连线穿透
```

**修法：填充用纯色，只让 `globalAlpha` 单独控制整体深度。**

```js
// 修复后
c2d.fillStyle = color;   // 纯色，不叠 alpha
c2d.fill();
```

### 2.3 顺带调整

| 参数 | 之前 | 现在 | 原因 |
|---|---|---|---|
焦点线 alpha | 0.72 | **0.40** | Bloom 后视觉 3~4px 白光柱，太刺眼 |
焦点线宽 | 1.2 | **0.85** | 同上 |
渐变 stop | 3 个 | **5 个** | 平滑过渡，无突兀峰值 |
长边衰减 | 无 | **有** | 709px 横线横跨全屏，按长度降亮度 |

## 三、③ 点击光圈太丑

### 3.1 之前的实现（三层套圈）

```
① 环形光晕（radial gradient 铺底）
② 内环（清晰冷白细环）
③ 外环（缓慢呼吸的淡环）
```

**用户说“太丑”—— 确实像套了三个圈。**

### 3.2 现在：纯柔光扩散

```js
if (isSel) {
  // 向外扩散的柔光（不是环）
  const sg = c2d.createRadialGradient(pr.sx, pr.sy, starR*0.9, pr.sx, pr.sy, expandR);
  sg.addColorStop(0, 'rgba(220,238,255,0.34~0.46)');
  sg.addColorStop(0.35, 'rgba(190,220,248,0.14)');
  sg.addColorStop(1, 'rgba(160,200,240,0)');
  c2d.fill();

  // 星形微微外扩一层（像"光散开"）
  traceStar4(pr.sx, pr.sy, starR * 1.28, concave);
  c2d.strokeStyle = 'rgba(225,240,255,0.26~0.36)';
}
```

**零环线，只有光。**

## 四、自检抓出的 4 个真实缺陷

### 缺陷 1：旧光晕代码残留（会破坏星形）

```js
// 自检发现 899~927 行还有旧代码
if (glow > 0 && showGlow) {
  c2d.arc(pr.sx, pr.sy, rr + glow, 0, TAU);  // ← 在星形外面画了个圆！
}
const coreR = ...;   // ← 重复声明
const haloR = ...;
```

**这是第一次说“星形成型”时的问题来源——圆把星形包住了。**

### 缺陷 2：`globalAlpha = alpha` 被误删

删除旧代码时连带删掉了深度透明度设置，导致前后节点没有明暗差异。

### 缺陷 3：“有标签无星形”

```
调研 z_norm = -1.25（太靠后）
旧 alpha = 0.26 + 0.30 * depth01
→ depth01 被钳制为 0 → alpha = 0.26
→ 再 × isDimmed 0.32 = 0.083
→ 星形几乎透明，只剩标签可见
```

**修法：alpha 下限提到 0.38（背半球），isDimmed 系数 0.32 → 0.40，最终下限 0.26。**

数学验证：
```
zw=-1.5 → alpha=0.38  (dimmed 后 0.26)
zw= 0.0 → alpha=0.85  (dimmed 后 0.34)
zw= 1.0 → alpha=1.00  (dimmed 后 0.40)
```

### 缺陷 4：测试脏状态污染

```
yaw: 15.427   ← 转了 2.45 圈
zoom: 0.5     ← 最小值
draggedCount: 3  ← 3 个节点被移动过
```

**这是我自己测试拖拽留下的**，导致截图里出现“幽灵线”。
**教训：测试脚本结束时应重置状态。**
