## 四、自检过程中抓到的 3 个真实 bug

### bug 1：`isFocus is not defined`

```js
// showDetail 里混入了 render 循环的配色代码
if (isFocus) brightMul = 1.9;    // isFocus 是 render 的局部变量
```

**修：** 删除整个误混入的配色块。

### bug 2：`Unexpected token 'else'`

```js
let brightMul = 1;
else if (isNeighbor) brightMul = 1.25;   // ← if 被误删，else 失去配对
```

**修：** 同上（整块删除）。

### bug 3：`color is not defined`

```js
'<span style="background:' + color + '"></span>'   // color 已随死代码删除
```

**修：** 改为 `n.color`。

### bug 4：详情面板 `display: none`

```js
function showDetail(n) {
  if (!n) { detail.style.display = 'none'; return; }
  const rows = [];        // ← detail.style.display = 'block' 被误删
```

**修：** 补回 `detail.style.display = 'block';`

### 教训

**这四个 bug 都是"删代码时误伤"造成的。**
每次删除区块后，必须检查：
1. 是否有配对的 `if/else` 被拆散
2. 是否有被删除的变量在后面还被引用
3. 是否有"副作用语句"（display/赋值）被误删

## 五、架构层面的问题

### 5.1 `main-agent` 不在 scene panel 系统里

**自检发现：** 我一度把 `main-agent` 加进 `hub.json`，结果报"未知面板类型"。

**真相：** `main-agent` 由 `index.js` 第 251-269 行直接挂到 `shell.sideEl`，**不在 scene panel 注册表**。

**设计上这是合理的**：
- 场景面板是"可变的、AI 可调度的"
- 主 Agent 是"固定的唯一交互入口"
- 两者分离是正确的架构

**但缺少文档说明**，容易误改。已在 `hub.json` 的 `meta.note` 中注明。

### 5.2 国色变量命名不够直观

```
--gu-shiqing  → 实际叫 --gu-qing
--gu-tenghuang → 实际叫 --gu-huang
--gu-zhusha   → 实际叫 --gu-chi
```

**建议（未执行）：** 增加别名变量
```css
--gu-shiqing: var(--gu-qing);
--gu-tenghuang: var(--gu-huang);
--gu-zhusha: var(--gu-chi);
```
