## 二、三个技术突破（这是真收获）

### 2.1 突破一：修掉"引擎地址自引用"

**症状**：AI 面板永远"引擎还没就绪"。

**根因**（`main.js` 第 980 行附近）：
```js
if (engineIsForeign) return 'http://127.0.0.1:' + SITE_PORT + '/chat';
```

复用外部引擎时，工作台强制走**自己**的 `/chat` 保活入口，形成自引用循环。

**修法**：
```js
if (engineIsForeign && process.env.DSH_EXTERNAL_VIA_CHAT !== '1') {
  const extTok = process.env.DSH_ENGINE_TOKEN || '';
  return extTok ? (BASE + '/?token=' + extTok) : (BASE + '/');
}
```

### 2.2 突破二：桌面版 token 不落盘 → 自己起引擎

**发现**：`dsh` 桌面版（44401）的 token **只在内存里**，不写日志、不落盘。

**解法**：用官方 CLI 起独立的 web 引擎：

```powershell
$env:DSH_HOME = "$env:USERPROFILE\.dsh"
& "...\runtime\cli\bin\dsh.cmd" --profile web --port 3080 --no-open
# 输出：dsh web: http://127.0.0.1:3080/?token=<TOKEN>
```

### 2.3 突破三：RPC 的真实 payload 格式

**光看 API 会以为是普通 REST，但必须带 `type:client-request` 包装**：

```json
{
  "type": "client-request",
  "rpcId": "r1",
  "method": "session/create",
  "payload": { "args": { "request": { "cwd": "..." } } }
}
```

**三步流程**：
```
① token → cookie   fetch(BASE + '/?token=' + token, { redirect: 'manual' })
② session/create   → sessionId
③ session/rename   → 标题
④ 写回 scenarios/<id>.json
```

## 三、卡住的部分：网关模型（诚实说明）

### 3.1 症状

```
本轮运行失败：当前请求的额度已用尽 (QUOTA)
模型：DeepSeek-V4.1-Flash
```

### 3.2 根因链（查明）

```
desktop profile（桌面版 44401）
  ✅ 有 dsh-our-free-model 插件
  ✅ cordis.patch.yml 里配了 provider: raccoon

web profile（CLI 起的 3080）
  ❌ 没有 dsh-our-free-model
  ❌ 只有 deepseek-official / deepseek-account 两个官方 provider
```

### 3.3 试过的修复

**① 给 web profile 加插件** → 安装成功但 bundle 解析失败（link 路径问题）

**② 克隆 desktop profile 成 web-gw** → 插件装上了（`dsh-our-free-model 2.8.0`）
   - 配置树里出现 `agent-default-model → provider: raccoon`
   - 运行时新增 21 个工具 ⇒ **插件确实加载了**
   - **但模型选择仍是 DeepSeek-V4.1-Flash，仍报 QUOTA**

**③ 显式 insert our-free-model 条目** → 已去掉重复，配置正确但行为未变

### 3.4 未解决的原因

`provider: raccoon` 在配置树里，但 **raccoon provider 没有真正注册到 LLM 服务**。
可能原因：
- 插件需要登录/账号态才能注册 provider（`channel-pack` 有 28 个账号）
- 或者 provider 注册依赖桌面版专有的 **EAC 协付渠道**
- CLI 模式可能不加载某些 desktop-only 路径

### 3.5 影响评估

| 影响 | 程度 |
|---|---|
架构完整性 | **无影响**（27/27 全绿） |
会话绑定 | **无影响**（11/11 已绑） |
AI 面板显示 | **无影响**（能显示真实引擎界面） |
**AI 能否真正对话** | ⚠️ **受影响**（配额用尽） |

**结论：这是 DSH 引擎的账号额度问题，不是我们架构的问题。**

### 3.6 给用户的建议

三个可行路径：

**A. 在桌面版 DSH 里直接用（推荐）**
桌面版能拿到 raccoon 网关模型。工作台连桌面版即可，只要能从桌面版拿到 token。

**B. 充值/换 DeepSeek 账号**
如果坚持用 CLI 起的 web 引擎，需要给 `deepseek-official` provider 一个有效账号。

**C. 等插件支持 CLI 模式**
`dsh-our-free-model` 2.8.0 的 raccoon 渠道可能需要桌面版专有的 EAC 组件。
