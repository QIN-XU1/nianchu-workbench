## 三、界面重设计：四次迭代

### 迭代 1：直接套 CSS（失败）

加了 `theme-terminal.css`，定义了 60+ 个语义颜色键。
**结果**：顶栏底栏出现，但主体还是白卡片。

### 迭代 2：加 JS 搬 DOM 做三段式（失败，已回滚）

写了 `tui-layout.js`，用 JS 把 body 内容装进 `#tui-shell` / `#tui-content`。
**结果**：**布局彻底崩了** —— 顶部两行重复、AI 面板被裁切、大片空白。

**教训：不要用 JS 搬 DOM 来改布局。** 原界面有自己的 flex 结构，硬搬会破坏它。

### 迭代 3：审计 + 强制归零（部分成功）

写了 `tui-audit.mjs` 实测：
```
圆角未归零：19 类
仍有阴影：15 类
字体族：206 个等宽 + 123 个系统 UI
```

补了 `theme-terminal-2.css` 强制归零。
**结果**：面板圆角 0px、阴影 none、边框统一，但**留白问题仍在**。

### 迭代 4：查真实原因 + 用对的色板（成功）

**用 `tui-diag-layout.mjs` 实测填充率**：
```
命令场景：cmd-neuron 107% / cmd-chat 94%   ← 正常
管线场景：pl-board 97% / pl-ai 94%          ← 结构正常
```

**留白不是 CSS 问题，是内容自然高度不够。**

修法：
- `sf-board-panel.js` 改绝对填充（`position:absolute;inset:0`）
- 产物列表 `flex:1` 撑满剩余高度
- 行高从 22px 紧凑化

**同时换成 dsh-TUI 的真实色板**（`theme-terminal-4.css`）：
```css
--tui-accent: #7DA1DE;      /* 雾蓝，不是 GitHub 蓝 */
--tui-text: #E8E6E0;        /* 暖白，不是纯白 */
--tui-card-bg: #242B3A;     /* 蓝灰卡面 */
--tui-input-bg: #000000;    /* 纯黑输入 */
--tui-prompt-border: #55606F;
```

**结果**：深色主题下效果明显改善。

## 四、webview 的矛盾（诚实说明）

**dsh-TUI 是纯终端，没有嵌入网页。我们的工作台有 6 个 webview。**

这是架构级差异，不是 CSS 能解决的：
- 引擎界面（`persist:harness`）× 2
- 免费 AI 站（`persist:webai-*`）× 4

**解法**：`tui-webview-theme.js` 提供三档（默认 off）
```
off   不动（网页原色，最真实）
soft  轻微压暗（brightness .92）
dark  反色适配（invert + hue-rotate，仅深色主题）
```

**默认 off，不干扰正常网页浏览。**
