## 二、原项目的关键设计（逐条摘录）

### 2.1 核心原则

> **「一个场景 = 一份 JSON。」**
> 「放进 `scenarios/` 目录即被自动发现：不需要注册、不需要改主进程代码。」
> 「**加场景 = 丢一份 json**：目录每次都重扫，不缓存列表。」

### 2.2 网格规则

> **「列数是可配的，行是等分的。」**
>
> | 字段 | 含义 | 默认 |
> |---|---|---|
> | `col` | 起始列，从 1 开始 | 自动 |
> | `row` | 起始行，从 1 开始 | 自动 |
> | `w` | 跨几列 | 2 |
> | `h` | 跨几行 | 2 |
>
> **三条规则：**
> 1. 只写 w/h 不写 col/row → 进自动流
> 2. 全都不写 → 自动排版，补洞拉伸填满
> 3. 写了起点 → 落在该格，向右跨 w、向下跨 h
>
> ⚠ 坐标是「**起点 + 跨度**」，不是终点。
> `col:4 w:1` 才是最后一列；`col:4 w:2` 会伸到第 5 列（越界）

### 2.3 cols 的用途

> 「列数是**比例的最小单位**。4 列能表达 1:3、2:2、3:1，**表达不了 2:3**。
> 要五分之三 / 五分之二，就把 cols 调大：」

```json
{
  "cols": 20,
  "panels": [
    { "id": "a", "w": 12 },   // 12/20 = 3/5
    { "id": "b", "w": 8  }    // 8/20 = 2/5
  ]
}
```

### 2.4 常见版式

| 版式 | 坐标 |
|---|---|
**上 3 下 1** | A `col1 row1 w3 h2` ｜ B `col4 row1 w1 h2` |
**左 1 右 3** | A `col1 row1 w1 h2` ｜ B `col2 row1 w3 h2` |
**左右各半** | A `col1 row1 w2 h2` ｜ B `col3 row1 w2 h2` |
**2 × 2** | 四个 `w2 h1` |
**上下通栏** | 两个 `w4 h1` |
**主区+侧栏+底部** | 主区 `w3 h2`｜侧栏 `w1 h2`｜工具条 `w4 h1` |

### 2.5 面板通用能力

```
┌───────────────────────────────────────────────────────┐
│ [01] 标题  小字              [自定义按钮…]  [▲]      │
│ ───────────────────────────────────────────────────── │
│  面板正文（渲染器自己画）                               │
└───────────────────────────────────────────────────────┘
```

| 部件 | 说明 |
|---|---|
序号 `01` | 面板在 json 里的顺序（补零两位），方便口头指认 |
小字 `sub` | 状态/路径，渲染器可随时更新 |
**▲ 展开** | AI 面板默认；其它写 `"expand": true`；ESC 也能收 |

### 2.6 数据分区

```js
const key = 'my-panel:' + meta.scenario + ':' + meta.id;
```
**why**：同一面板类型会被多个场景复用，不带前缀就会互相覆盖。

## 三、补上的 5 项能力

### 3.1 `ui/panels/grid.js` —— 网格布局引擎

```js
computeLayout(scene)       // 读 cols、按 col/row/w/h 摆放、越界检测、自动补洞
applyGrid(gridEl, layout)  // grid-template-columns: repeat(cols, minmax(0,1fr))
applyCell(el, cell)        // grid-column / grid-row
```

**完整实现了原项目三条规则：**
- 有坐标 → 按坐标落位
- 坐标只写一半 → 告警 + 自动流
- 重叠 → 告警 + 找空位
- 无坐标 → 行优先扫描补洞
- 越界 → 告警 + 按实际列数渲染（不画歪）
- 实在放不下 → 追加最底部

### 3.2 `ui/panels/frame.js` —— 面板容器

宿主自动装配：
- **序号徽标**：`padStart(2, '0')`
- **▲ 展开到最高**：占位格钉住版面 + 覆盖层，ESC 可收
- **scenario 注入**：`meta.scenario = sceneId`
- `setSub()` / `addAction()` / `storageKey()`

### 3.3 `ui/index.js` —— renderScene 改用新引擎

```js
const layout = grid.computeLayout(scene);
grid.applyGrid(shell.gridEl, layout);
for (const cell of layout.cells) {
  const frame = frameMod.createPanelFrame(p, sceneId, i);
  grid.applyCell(frame.el, cell);
  await registry.renderInto(frame, p, ctx);
  shell.gridEl.appendChild(frame.el);
}
```

### 3.4 `ui/panels/registry.js` —— 新增 `renderInto`

渲染到已有 frame，不再自己建容器。

### 3.5 `工具/scene-edit.mjs` —— 场景编辑器（**核心交付**）

让场景**真正可自定义修改**。

**八个子命令：**

| 命令 | 作用 |
|---|---|
`--types` | 列出 10 种已注册面板类型 |
`--check <id>` | 校验：文件名=id / type已注册 / 无越界 / 无重叠 |
`--check-all` | 校验全部场景 |
`--show <id>` | ASCII 版式预览 |
`--layout <id> --preset <版式>` | 应用预设版式（8 种） |
`--layout <id> --cols 20` | 改列数（实现任意比例） |
`--set <id> --panel <pid> --col N --row N --w N --h N` | 改单个面板坐标 |
`--add <id> --type <t> --title <名字>` | 加面板（自动补位） |
`--remove <id> --panel <pid>` | 删面板 |

**8 种预设版式：**
`single` / `left-right-half` / `left-1-right-3` / `top-3-bottom-1` /
`grid-2x2` / `main-side-toolbar` / `stack` / `neuron-only`

**ASCII 预览示例（中枢）：**
```
       1              2              3              4
       ┌──────────────├──────────────├──────────────├──────────
1      │#hub-neuron   │              │              │
       │4×5 neuron    │              │              │
```

## 五、神经元 v4 重做

### 5.1 v2/v3 的六个问题

| # | 问题 | 具体 |
|---|---|---|
① | 大片空白 | 半径用 `Math.min(W,H)`，水平浪费 40% |
② | 节点太小 | 场景节点 5~10px |
③ | 标签稀疏 | 大部分节点没名字 |
④ | 结构不明 | 看不出层次 |
⑤ | 无纵深 | 背景纯黑 |
⑥ | **节点重复** | 中枢画了两次 |

### 5.2 v4 的设计

**核心理念：神经元不是装饰，是导航。**
每个节点都要能回答：这是什么、现在什么状态、点它去哪。

#### 布局：三环同心椭圆

```
  外环（场景层）  rx = W × 0.42, ry = H × 0.38
  内环（记忆层）  半径 = 外环 × 0.52
  中心         中枢
```

**为什么用椭圆**：面板是宽扁的，用圆会水平浪费 40%。

#### 六项改进

| 项 | v3 | v4 |
|---|---|---|
记忆节点标签 | 单字无意义 | **不画标签**（纯结构标记，空心小圈） |
内环距离 | 0.62 太近 | **0.52 拉开层次** |
中枢节点 | 静态 | **始终呼吸动画** |
场景节点 | 无状态区分 | 待命实心 / 活跃光晕脉冲 |
悬停 | 只高亮自己 | **高亮整条链路** |
背景 | 纯黑 | 径向渐变 + **同心椭圆 + 24 向刻度** |

#### 修复的 bug
1. **跳过 isHub 场景** —— 消除中枢重复
2. **记忆节点不画标签** —— 消除无意义单字
3. **椭圆布局** —— 消除大片空白
