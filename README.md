## 三条不可退让的规则

1. **不把「已写入」当「已验证」** —— 代码写完 ≠ 验证通过
2. **拿不到证据标 `UNKNOWN`** —— 不算通过、不算打平
3. **不可比不算平** —— 拿不到源码的对手单列"不可比"，不混进输赢
