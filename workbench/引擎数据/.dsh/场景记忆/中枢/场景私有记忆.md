## 五、坑与决策

### 2026-11-10 · 记忆神经元插件的三个关键教训

1. **坐标点击不可靠，交互验证要用测试驱动**
   屏幕坐标点击依赖 DPI（本机 1.25）、窗口位置、侧边栏折叠状态、滚动位置。
   实测：同一坐标在不同窗口尺寸下命中不同元素。
   正解：从渲染树找组件实例，直接调 props 回调（`card.props.onPick(id)`），
   再用 93 项测试断言状态变化。可 CI 化，失败能定位到具体环节。

2. **写 API 前必须读真实源码**
   三处错误 API 导致 Harness 无法启动：
   - `scope.effect()`（把注入回调参数当 Cordis Scope）→ 应 `injected.get(name)`
   - `kind: 'prefix'` 抢占整个前缀 → 应 `'exact'`
   - `styles.insert()` 是另一条 lane 的闭包参数，`factory(require)` 收不到
   后读 `_research/DSH-client-plugin-spec.md`（69 KB 源码级报告）才全部理清。

3. **静默失效比报错更危险**
   - `styles.insert()` 让整包 client 静默失活（不报错，只是什么都不出现）
   - `routes` 用对象身份做 Map key 失效（不报错，只是路由不生效）
   - `dsh.client.inject` 写错包名静默忽略
   对策：测试必须断言"该出现的有没有出现"，不能只看"有没有报错"。
