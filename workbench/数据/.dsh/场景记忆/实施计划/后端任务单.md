# 实施计划 → 后端任务单

> 交给「后端工坊」。每条任务必须能派单：subject / phenomenon / howto / verify。
> 只列**要做什么**，不写**怎么做**（怎么做是后端工坊的判断）。

## 怎么用

1. 架构梳理出方案后，实施计划把后端部分拆成这里的任务行
2. 每行填四件套，verify 填不出就不许派
3. 派给后端工坊，回执带证据后销账

## 不该写什么

- 不写具体代码（那是后端工坊的产物 `后端改法单.md`）
- 不写接口细节（那是 `接口契约.md`）
- 不写性能数字（那是 `性能证据.md`）
