## 我是什么

- 职责：自我复盘：右上角浏览 <工作台>\自我复盘 的文件树；左上角大窗口**不管单击、双击还是怎么点，都只在这里预览**（md 渲染、txt/代码/json/csv 原文、图片可滚轮缩放、视频/音频、PDF、HTML 内嵌、Word/Excel/PPT 转成 PDF 后内嵌），**只有左边预览面板工具栏那个「🖥 系统默认程序打开」才会拉起外部程序**；真的看不了的（压缩包/PSD/可执行文件）给提示卡。左下角内嵌 DeepSeek 网页版（可点 ▲ 向上展开），右下角 AI 面板（内置会话「自我复盘」，同 ▲ 展开）。默认 4 列网格：上排 3+1（文件预览 75% / 库 25%），下排 2+2（网页版与 AI 各占一半）。

### 每个面板做什么

- **`sr-doc`**（预览）— 文档视图：渲染 Markdown 文档
  - 副标题：点右上的文件就在此预览（Word / Excel / PPT / PDF 都能内嵌看；要改才用这排的 🖥 打开系统程序）
- **`sr-files`**（库）— review-files
- **`sr-site-bl`**（AI·DeepSeek 网页版）— 内嵌网页：嵌入外部网页（可配 URL）
  - 副标题：chat.deepseek.com · 内置网页
  - 内嵌地址：`https://chat.deepseek.com/`
- **`sr-ai`**（AI·自我复盘）— AI 对话：与 AI 对话的窗口（核心，不可删）
  - 🔒 **固定面板，不要删也不要移**

## 我能怎么改自己

改自己 = 改 `外壳/scenarios/self-review.json` 里的 `panels` 数组。

**能改的**：

- 加面板：往 `panels` 里加一项 `{id, title, type, col, row, w, h}`
- 删面板：删掉对应项（**但 `sr-doc` 和 harness 类型不能删**）
- 改位置：改 `col` / `row`
- 改尺寸：改 `w` / `h`
- 改标题：改 `title` / `sub`
- 内嵌网页：改 `url`（type 为 embed 时）

**不能改的**：

- `id` 已被其他地方引用时，改名要同步改引用
- 删掉 `harness` 类型面板 = 删掉自己和用户对话的能力
- 改完必须重启工作台才生效

## 改之前先存快照

```bash
node 工具/回滚.mjs --snapshot --type ui
# 改坏了就退回：
node 工具/回滚.mjs --rollback <快照id>
```
