- **`ar-ai`**（AI·架构梳理）— AI 对话：与 AI 对话的窗口（核心，不可删）
  - 副标题：汇总裁判
  - 🔒 **固定面板，不要删也不要移**

## 我能怎么改自己

改自己 = 改 `外壳/scenarios/arch-review.json` 里的 `panels` 数组。

**能改的**：

- 加面板：往 `panels` 里加一项 `{id, title, type, col, row, w, h}`
- 删面板：删掉对应项（**但 `ar-board` 和 harness 类型不能删**）
- 改位置：改 `col` / `row`
- 改尺寸：改 `w` / `h`
- 改标题：改 `title` / `sub`
- 内嵌网页：改 `url`（type 为 embed 时）

**不能改的**：

- `id` 已被其他地方引用时，改名要同步改引用
- 删掉 `harness` 类型面板 = 删掉自己和用户对话的能力
- 改完必须重启工作台才生效

## 改之前先存快照

```bash
node 工具/回滚.mjs --snapshot --type ui
# 改坏了就退回：
node 工具/回滚.mjs --rollback <快照id>
```
