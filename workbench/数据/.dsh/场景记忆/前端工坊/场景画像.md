### 每个面板做什么

- **`fe-preview`**（页面预览）— 内嵌网页：嵌入外部网页（可配 URL）
  - 副标题：查 CSS / 布局 / 可访问性规范
  - 内嵌地址：`https://developer.mozilla.org/zh-CN/docs/Web/CSS`
- **`fe-files`**（源码）— review-files
  - 副标题：看要改的那几个文件
- **`fe-board`**（管线位置）— 管线看板：显示上下游关系的流程图
  - 副标题：该等谁、该给谁
- **`fe-ai`**（AI·前端工坊）— AI 对话：与 AI 对话的窗口（核心，不可删）
  - 副标题：出改法单与可判定验收标准
  - 🔒 **固定面板，不要删也不要移**

## 我能怎么改自己

改自己 = 改 `外壳/scenarios/frontend-craft.json` 里的 `panels` 数组。

**能改的**：

- 加面板：往 `panels` 里加一项 `{id, title, type, col, row, w, h}`
- 删面板：删掉对应项（**但 `fe-preview` 和 harness 类型不能删**）
- 改位置：改 `col` / `row`
- 改尺寸：改 `w` / `h`
- 改标题：改 `title` / `sub`
- 内嵌网页：改 `url`（type 为 embed 时）

**不能改的**：

- `id` 已被其他地方引用时，改名要同步改引用
- 删掉 `harness` 类型面板 = 删掉自己和用户对话的能力
- 改完必须重启工作台才生效

node 工具/回滚.mjs --snapshot --type ui
