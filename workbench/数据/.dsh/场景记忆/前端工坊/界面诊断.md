> 这份文档是基于**真实截图**的诊断，不是猜测。
> 截图位置：`prototype/shots/02-*.png`

## 一、最致命的问题：两套视觉体系被硬拼在一起

这是**根子问题**，其他问题都是它的表现。

```
┌─────────────┬──────────────────────┬──────────┐
│  我们的壳    │    引擎原生 AI 面板    │  我们的   │
│  深色自定义  │    白底 / 浅色        │  深色     │
│  #0E1114    │    #FFFFFF           │  #0E1114  │
└─────────────┴──────────────────────┴──────────┘
```

**同一个窗口里，左边深色、中间纯白、右边深色。**

这不是「配色不统一」，这是**两个产品拼在一起**：
- 左边的面板（管线/文档/网页）是我们写的，用 theme.js 的 token
- 中间的 AI 对话是引擎（DSH）的 webview，我们改不了它的样式
- 右边中枢侧栏又是我们自己写的

用户看到的是：**用了两套设计语言的产品。**

### 这个问题的本质
我们把「AI 对话」这个核心功能**外包给了引擎的 UI**。
引擎 UI 是别人的产品（DeepSeek 的界面），它有自己的设计体系。
只要还用 webview 嵌引擎 UI，就永远不可能有一个完整统一的设计。

### 三条可能的路
| 方案 | 做法 | 代价 |
|---|---|---|
| A. 注入 CSS 强制改引擎 UI | 通过 webview 注入深色主题 | 脆弱，引擎一升级就坏；且仍受限于它的 DOM 结构 |
| B. 自己做 AI 对话 UI | 不嵌引擎 UI，直接用引擎 RPC + 自绘对话界面 | 工作量大，但**这是唯一能真正统一设计的路** |
| C. 全部改成浅色 | 放弃我们的深色壳，向引擎看齐 | 最省事，但丧失品牌感，且左侧面板重做 |

**推荐 B**，但可以分期：先做 A 缓解，再逐步迁移到 B。

## 二、具体问题清单（按严重程度排序）

### P0 级（一眼看出不专业）

**1. 中间 AI 面板纯白，刺眼且割裂**
- 实测：`02-research.png` 中间区域是 #FFFFFF 白底
- 而左右两侧是 #0E1114 深色
- 用户每次切场景都会经历「深→白→深」的视觉跳变

**2. 双层顶栏，信息重复**
```
┌────────────────────────────────────────────┐
│ DSH 工作台   [Electron]                    │  ← 第 1 层（系统窗口栏）
├────────────────────────────────────────────┤
│ 01 记忆神经元  拖拽旋转·滚轮缩放·点击节点   │  ← 第 2 层（面板标题）
├────────────────────────────────────────────┤
│ 记忆神经元                            [按钮]│  ← 第 3 层（面板内标题，重复！）
```
**同一个面板标题出现了两次**（`01 记忆神经元` 和 `记忆神经元`）。

**3. 面板编号 `01 02 03 04` 毫无意义**
- 这些数字是网格坐标派生的，用户看不懂
- 而且 `01` 和 `记忆神经元` 之间用一个细线分隔，视觉上像「序号+标题」，但实际没有语义

**4. 神经元图信息密度极低**
- 实测 `02-hub.png`：整屏只有 10 个节点，90% 是黑色空白
- 节点标签**重叠**：`故障分析` 和 `前端工坊` 叠在一起看不清
- 这是「看起来很酷但没有用」的典型

**5. 分割线是粗黑实线**
- 面板之间用 ~2px 的纯黑线分隔
- 2025 年的标准是用**亮度差 + 1px 半透明边框**，不是黑色实线

### P1 级（细节不专业）

**6. 场景切换没有任何过渡**
- 点顶上场景 → 整个界面瞬间替换
- 没有淡入、没有骨架屏，视觉上很"跳"

**7. 右侧中枢侧栏与左侧风格不统一**
- 右侧是圆角卡片、大留白
- 左侧是紧凑面板、小圆角

**8. 状态栏「就绪」孤立在左下角**
- 只有两个字，没有上下文

**9. 面板标题栏的说明文字过长**
- `显示竞品功能矩阵，产出自动发给「架构梳理」` —— 26 个字
- 在窄面板里会截断

**10. `frontend-craft` 场景网页加载失败**
- 实测：`ERR_CONNECTION_REFUSED`，url 指向 `http://127.0.0.1:27606`
- 但实际 Web GUI 端口已变（见运行时上下文）
- **这是真 bug，不是设计问题**

## 三、做得对的地方（不要改坏）

1. **神经元图的动效**（旋转/缩放/拖拽）—— 视觉上确实有质感
2. **面板功能的完备度** —— 网页/文件/文档/管线图该有都有
3. **深色主题的方向是对的** —— 暖色种子色（朱红）比冷灰好
4. **顶部场景标签的排布** —— 一行放 12 个场景，没有换行混乱

---

## 四、给重设计的硬约束

1. **必须解决「深/白」割裂** —— 这是用户最直观的不满
2. **面板标题只能出现一次**
3. **去掉无意义的 `01 02 03` 编号**（或改成有语义的标识）
4. **神经元图要么提高信息密度，要么改成更有用的形态**
5. **分割线用半透明边框，不用黑实线**
6. **修 `frontend-craft` 的 embed url**
7. **保持深色主题方向**
