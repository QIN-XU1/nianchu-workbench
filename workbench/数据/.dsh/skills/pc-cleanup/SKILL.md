# 本地电脑 · 技能

> 场景 id：`pc-cleanup`
> 这份技能记录："清理活具体怎么做才不闯祸"

---

## 一、开工前必做

### 1.1 先只读盘点，不动手

**这是硬规矩：盘点和动手必须分成两步。**

> **⚠ 2026-11-11 修正：本节原来写的三个命令都不存在。**
> `清理根目录.mjs` / `清理临时目录.mjs` / `梳理清理.mjs` —— 工具目录里没有这三个文件，
> 照着敲只会报 "Cannot find module"。
>
> 实际能力是界面里的四个只读面板（主进程 `pc:*` IPC），不是命令行工具。

**第一步：只读，出清单（走界面，不要敲命令）**

| 面板 | 看什么 | 对应 IPC |
|---|---|---|
| 磁盘分区 | 各盘总量 / 已用 / 剩余 | `pc:drives` |
| 磁盘大户排行 | 最大的文件/目录（默认扫 C:） | `pc:toplarge` |
| 可清理体检 | 分门别类列出可清项与体积 | `pc:junk` |
| 清理台账 | 已清理记录（只进不改） | `pc:ledger` |

**在终端里要看这些数据**，走引擎 RPC 或界面面板；
不要指望有 `清理*.mjs` 这种命令 —— 它们不存在。

**判据：** 清单出来之前，一行删除命令都不许敲。

> 本场景**没有直接删除的权限**。产出是「该清什么、各多大、风险是什么」的判断，
> 实际删除动作由用户在界面上确认后执行。这样设计是因为删错不可逆。

### 1.2 确认这是"该清的"

| 该清 | 不该清 |
|---|---|
过期安装包 | 用户文档 |
编译缓存 | 素材/媒体 |
临时目录（>7 天） | 会话库 |
日志 / spill | 备份 |
旧快照 | 私人数据 |

## 二、标准流程（五步）

### 第 1 步：只读盘点

跑三个盘点工具（全部默认空跑），收集：
```
· 根目录散文件
· 超过 7 天的临时目录
· 死重量（过期安装包/编译缓存/浏览器 profile/spill）
```

### 第 2 步：分类出清单

**必须分三档：**

| 档 | 内容 | 处置 |
|---|---|---|
**可直接删** | 缓存/临时/编译产物/过期安装包/日志/spill | 可再生 |
**进回收站** | 用户文档/素材/媒体/会话库/备份 | 不可再生 |
**不动** | 系统目录/私人数据/别人的东西 | 只报 |

### 第 3 步：在面板回一句，等点头

```
"准备清这些：<清单摘要>
 可直接删 N 项（M MB）
 进回收站 N 项（M MB）
 不动 N 项
 等你点头。"
```

**默认不问的例外：**
凡"明确是垃圾"（超期 `_临时`、散落 `.bak`、缓存/spill、旧快照）
→ 直接动手，不用问。这是机主定的。

### 第 4 步：动手

**硬规矩：**
```
⛔ 不许用 Remove-Item -Force / rmSync / del
✅ 可再生类：可以直接删
✅ 其它：必须走回收站
```

### 第 5 步：记三处

```
① 外壳/data/pc-cleanup-log.json     ← 台账
② 场景记忆/本地电脑/_文件索引.md      ← 处置记录
③ 场景记忆 §〇                       ← 交接
```

## 三、验收标准

**怎么算这次清理做完了：**

```
✅ 盘点结果有清单（不是"我觉得该清了"）
✅ 每一项都分了档（可删/回收站/不动）
✅ 台账里有完整记录（时间/路径/大小/处置方式）
✅ 原始数据可恢复（进回收站的能找回）
✅ 场景记忆 §〇 已更新
```

**不达标的表现：**
```
❌ 直接删了没说清了什么
❌ 用了 -Force 抹掉
❌ 台账缺失
❌ 删完不能说明"为什么这些可以删"
```

## 四、常见坑

### 坑 1：把"能删"和"该删"混一起

**表现：** 看到大文件就删。
**后果：** 删了用户在用的素材。
**避免：** 强制分三档，不可再生的必须进回收站。

### 坑 2：用 -Force 图省事

**表现：** `Remove-Item -Force`。
**后果：** 绕开回收站 = 不可还原。
**真实事故：** 12.1 GB 的旧副本被彻底删除，回收站里找不到。

### 坑 3：替别人删东西

**表现：** 看到别的场景的临时目录也顺手清。
**后果：** 那个场景的活干到一半被破坏。
**避免：** 只清自己认领的，别人的发请求。

### 坑 4：清单太粗

**表现：** "清了 2GB 垃圾"。
**后果：** 无法复核，出事查不到。
**避免：** 每项都要有完整路径 + 大小 + 处置方式。
