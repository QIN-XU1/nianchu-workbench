# 自我复盘 · 技能

> 场景 id：`self-review`
> 这份技能记录："私人内容怎么管才不丢不乱"

---

## 一、开工前必做

### 1.1 先判断"私人 vs 工作"

**这是第一道分界线。**

```
问自己：这个内容如果公开了，会不会有问题？
  会  → 私人内容，进 自我复盘\，永不进共享层
  不会 → 可能是工作内容，按正常流程
```

**判据：** 拿不准就按"私人"处理。宁可多隔离，不可误共享。

### 1.2 确认不写敏感信息

**绝对不写进任何文件：**
```
· 密码 / 密钥 / token
· 身份证号 / 银行卡号
· 完整的手机号（可只存后四位）
```

---

## 二、标准流程（四步）

### 第 1 步：分类归档

**固定分类（不要新建顶层目录）：**

```
自我复盘/
  ├── 个人档案/
  ├── 我的知识库/
  ├── 证件学历/
  ├── 健康/
  ├── 合同/
  └── _场景记忆/
```

**判据：** 顶层白名单制，新分类要先问用户。

### 第 2 步：命名规范化

**格式：** `<类别>_<日期>_<主题>.md`

```
例：健康_20261109_年度体检.md
```

**为什么：** 不规范的命名三个月后自己也找不到。

### 第 3 步：过期内容归档不删

```
当季在用 → 留在原目录
过季 → 移入 归档/YYYY/
```

**绝对不删。** 私人内容删了就是永久丢失。

### 第 4 步：更新索引

```
我的知识库/README.md  ← 目录索引
场景记忆 §〇          ← 交接
```

---

## 三、验收标准

**怎么算这次活做完了：**

```
✅ 内容已归档到正确的分类目录
✅ 命名符合规范（类别_日期_主题）
✅ 没有敏感信息（密码/身份证号/完整手机号）
✅ 索引已更新（能通过 README 找到）
✅ 私人内容没有进共享层
```

**不达标：**
```
❌ 随手扔在工作区根目录
❌ 文件名看不懂是什么
❌ 索引没更新，三个月后找不到
❌ 私人内容进了 _共享记忆/
```

---

## 四、常见坑

### 坑 1：把私人内容放进共享层

**表现：** 图方便，把健康数据放进 `_共享记忆/`。
**后果：** 所有场景都能读到。
**避免：** 强制走"私人 vs 工作"判断。

### 坑 2：删过期内容

**表现：** "这份合同过期了，删了吧"。
**后果：** 永久丢失，可能需要时找不回。
**避免：** 只移入归档，绝不删。

### 坑 3：命名随意

**表现：** `新建文档.md`、`副本(2).md`。
**后果：** 三个月后完全不知道是什么。
**避免：** 强制 `类别_日期_主题` 格式。

### 坑 4：记录敏感信息

**表现：** 方便起见把密码写在笔记里。
**后果：** 一旦泄露不可挽回。
**避免：** 绝对禁止。要记就记"密码在哪"而不是密码本身。

---

## 五、铁律

```
① 绝不写密码/密钥/身份证号
② 私人内容永不进共享层
③ 过期只归档不删
④ 拿不准先问用户，不猜
⑤ 只写自己的记忆
```
