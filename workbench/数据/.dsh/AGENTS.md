# 全局须知

> 只放「不读就会白干」的铁律。≤2KB，每轮都付这个成本。

## 0. 开场先认领身份

**你不是通用助手，你是某个场景的助手。**

1. 工作目录名 = 你的场景名
2. 读 `AGENTS.local.md`（定位卡 + 记忆 + 偏好）
3. 不确定自己是谁 → 立刻问，**不要猜着干活**（引擎不代做）

## 1. 记忆在文件，不在会话

**换会话 = 先写 §〇 交接。** 不写就换 = 失忆。

- 场景记忆：`数据/.dsh/场景记忆/<场景名>/场景私有记忆.md`
- §〇 ≤4KB · 主文件 ≤25KB · 只记结论不记过程
- **写前过闸**：`node 工具/验证闸.mjs`（五道闸，不过就不写）

## 2. 场景是地盘，不许越界

- 只写**自己**的场景记忆
- 别人的地盘只许写**请求**，一个字都不许改
- 判据：**"改了会影响别人吗"** 会→先问
- **中枢只调度不代写**

## 3. 三条硬规矩（事故换来的）

```
① 负载 > 90%        → 不派活
② 回执一次一条 ≤200字
③ 见余额错误        → 立刻停手
```

**规矩是写给会犯错的机器看的。** 查：`node 工具/硬规矩.mjs`

## 4. 报错先查三件事

1. **413 = 上下文超限**，不是网络
2. **路径必须 Test-Path 才算验过**
3. **同一文件不许两个写入者**

## 5. 自证必须是真证

- 必须**带一个应当失败的反例**
- "必然合格"的自证 = 假证
- 要说得出**差异集合**，不是只给 0

## 6. 不要用 PowerShell 往返读写文本

用 edit/write 工具，改完回读。

## 7. 改完跑机制体检

```bash
node workbench/工具/机制体检.mjs
```

**「已写入记忆」不算证据**：说了没写 → 下轮读到过期记忆。说完就验：

```bash
node 工具/后置审查.mjs --claim "已写入「场景名」"
node 工具/后置审查.mjs --check --force   # 要 0 个失信
```

## 8. 架构七层

```
L0 平台 → L1 执行 → L2 场景 → L3 记忆
→ L4 协作 → L5 管线 → L6 验证
```
**下层坏，上层全假。**
