# 对比矩阵 技能

> 「我们更好」如果只靠总分，会掩盖「某一维我们落后很多」。
> 判据：**每一格都有证据吗？口径公平吗？某一维落后会不会被总分掩盖？**

## 什么时候用

- 多方案/多产品逐维对比
- 要评审「全面领先」这类声明
- 要找出「哪一维其实落后」

## 什么时候**不**用

- 单一指标比较（直接比数字）

## 第 1 步：每格带证据

- 每个格子标：有/部分/无/判不了（或等价分级）
- **每格附证据**（路径:行号 / 命令输出 / 截图）
- 证据缺失 → 判不了（不猜）

## 第 2 步：公平比较口径——用「零落后」而非「净胜」

净胜 = 我们的分数 - 对手分数。**净胜为正也可能掩盖某维落后**（其它维赢回来）。

「零落后」= **没有任何一维我们比对手差**。这才是「实质不落后」的判据。

## 第 3 步：不可比项要排除，不参与胜负

对手是闭源/无源码/非系统时，该维判「判不了」，**从比较里排除**，不要硬凑分数。

## 第 4 步：诚实标注「口径是我方定的」

矩阵分数若由我方评，必须声明：「这是我方口径下的不落后，不是客观最强」。

## 反例（写下来防复发）

- ✗ 只看总分 → 掩盖单维落后
- ✗ 每格无证据 → 结论不可复算
- ✗ 不可比项硬凑分数 → 虚假对比
- ✗ 不声明口径 → 让人误以为是客观评测

## 自检清单

- [ ] 每格带证据（路径/输出/截图）
- [ ] 用「零落后」判据而非只看净胜
- [ ] 不可比项排除，不参与胜负
