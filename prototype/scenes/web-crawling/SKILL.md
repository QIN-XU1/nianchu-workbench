# 网页抓取 技能

> 爬虫的失败多为三种：**太快被封**、**重复抓浪费**、**没看 robots 惹麻烦**。
> 判据：**你的抓取，对目标站是「礼貌的客人」还是「DDoS」？**

## 什么时候用

- 采集公开数据
- 监控页面变化
- 数据集成

## 什么时候**不**用

- 有官方 API（优先用 API）
- 数据受版权/隐私保护（先确认合法性）

## 第 1 步：合法性（先问清）

| 检查 | 说明 |
|---|---|
| **robots.txt** | 遵守允许/禁止 |
| 服务条款 | 是否禁止抓取 |
| 版权 | 数据能否使用 |
| 个人数据 | 隐私合规（见 `data-retention`） |
| 频率 | 别造成负担 |

⛔ 无视 robots + 高频抓 = 可能被封 IP/法律风险。

## 第 2 步：礼貌限速

| 项 | 建议 |
|---|---|
| 并发 | 低（按站点） |
| 间隔 | 请求间延迟 |
| 遵守 Retry-After | 429 时退避 |
| 避开高峰 | |

## 第 3 步：去重与增量

| 手段 | 说明 |
|---|---|
| URL 规范化 | 去重前统一格式 |
| 已抓集合 | 记录已抓 URL |
| 增量 | 按更新时间/ETag 只抓变了的 |
| 内容哈希 | 内容变没变 |

## 第 4 步：反爬应对（合法范围内）

| 反爬 | 应对 |
|---|---|
| User-Agent 检查 | 用真实 UA |
| 频率限制 | 放慢 |
| JS 渲染 | headless 浏览器 |
| 验证码 | 尊重（不破解） |
| IP 封 | 别硬绕（换策略/申请授权） |

⛔ 破解验证码/绕过反爬 = 越界，可能违法。合法范围内应对。

## 第 5 步：健壮性

| 项 | 说明 |
|---|---|
| 失败重试 | 有限次，退避 |
| 解析容错 | 页面结构变不崩 |
| 断点续抓 | 中断可续 |
| 监控 | 成功率/封禁 |

## 输出格式

**结论**：`四态: PASS | WARN | FAIL | UNKNOWN`
- PASS = 合法 + 限速 + 去重增量 + 健壮
- WARN = 有抓取但无去重/限速
- FAIL = 无视 robots / 高频 / 破解反爬
- UNKNOWN = 拿不到目标站点

## 假阳性清单（这些不算「爬虫好」）

- 能抓但无视 robots
- 无去重（重复抓）
- 高频

## 假阴性清单（最常漏的 8 类）

1. **无视 robots**
2. **无去重**（重复抓）
3. **无增量**（全量重抓）
4. **频率太高**（被封）
5. **不遵守 Retry-After**
6. **破解反爬**（违法风险）
7. **解析无容错**（页面变就崩）
8. **无断点续抓**

## 边界（如实说清）

- 合法性因地区/站点而异，需具体确认
- 反爬对抗是军备竞赛，最好拿授权/API
- 本技能不实现，只设计
