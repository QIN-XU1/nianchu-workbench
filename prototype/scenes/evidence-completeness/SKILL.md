# 证据完整性 技能

> 格子写了「有」，证据栏却是「有实现」三个字——这等于没证据。
> 判据：**每格证据非空、够长、是完整句子、没被截断吗？**

## 什么时候用

- 对比矩阵、证据表、验收记录
- 要评审「证据充分」这类声明
- 发现「证据栏全是敷衍词」

## 什么时候**不**用

- 无证据栏的自由文本

## 第 1 步：四条合格判据

| 判据 | 不合格示例 |
|---|---|
| 非空 | 空字符串 |
| 够长（超过阈值） | 「有」「见代码」 |
| 有句末标点 | 「实现了记忆功能」后面没标点、也不像完整句 |
| 未被截断 | 以「…」或半句结尾 |

## 第 2 步：区分「我们自己的格」与「对手的格」

- 我们自己的格不合格 → 必须修（我们对自己要求高）
- 对手的格不合格 → 记为 WARN（我们无法补全对手证据）

## 第 3 步：WARN 不阻断，但必须可见

不合格格数以 **WARN（exit 3）** 报出，不阻断流程，但报告里要能看到「有几格不合格、其中截断几格」。

## 反例（写下来防复发）

- ✗ 证据栏写「有实现」 → 无法核验
- ✗ 截断的证据当完整 → 断章取义
- ✗ 只统计总数不报不合格数 → 掩盖敷衍
- ✗ 把 WARN 当 PASS → 假绿

## 自检清单

- [ ] 四判据（非空/够长/句末/未截断）
- [ ] 我方格与对手格分开统计
- [ ] WARN 报出不合格数与截断数
