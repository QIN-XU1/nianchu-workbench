# 证据溯源 技能

> 「我们比对手强」这种结论，如果不标证据来源，就是自说自话。
> 判据：**每个结论格子，都能说清证据是哪来的吗？是读到对方源码，还是只有我们自己写的描述？**

## 什么时候用

- 做竞品/方案对比矩阵
- 要评审「这个结论有证据吗」
- 发现「结论很漂亮但找不到出处」

## 什么时候**不**用

- 纯内部实现说明（不涉及对比）

## 第 1 步：四类证据，逐格标注

| 类 | 含义 | 可信度 |
|---|---|---|
| **REAL** | 路径真实落在对方仓库里，读到源码 | 最高 |
| **MIXED** | 部分是对方源码、部分是我们推断 | 中 |
| **ABSENT** | 对方没有 / 我们没找到 | 中 |
| **OWN** | 只有我们自己的文字描述，没有对方源码 | 最低 |
| **UNKNOWN** | 判不了 | — |

**OWN 不能当 REAL 用**——这是最容易自欺的地方。

## 第 2 步：统计与阈值

- 算出各类占比（如 REAL 63.5% / ABSENT 36.5% / OWN 0）
- **OWN 比例高 = 对比不可信**，要明确写出来，不能藏

## 第 3 步：路径必须真能打开

每条 REAL 证据的路径，都要能被脚本验证「文件存在」。不存在的路径是假证据。

## 反例（写下来防复发）

- ✗ 把「我推测对手有」写成「对手有」 → OWN 冒充 REAL
- ✗ 证据路径是编的 / 已删除 → 无法复算
- ✗ 只统计总数不分类 → 掩盖 OWN 占比
- ✗ 用「详见文档」代替路径 → 追不到

## 自检清单

- [ ] 每格标了 REAL/MIXED/ABSENT/OWN/UNKNOWN
- [ ] REAL 路径经脚本验证真实存在
- [ ] 统计各类占比并公开
- [ ] OWN 占比高时明确声明不可信

## 参考实现指路

本仓库 `tools/evolve/audit-evidence-provenance.mjs`：扫描矩阵 899 格，按 REAL/ABSENT/OWN/MIXED 分类并验证路径存在（实测 REAL 571 · 63.5% · OWN 0）。

## 实测数据（本仓库，可复算）

```
node tools/evolve/audit-evidence-provenance.mjs
```

实测结果（矩阵 899 个证据格）：

| 类 | 数量 | 占比 |
|---|---|---|
| REAL（路径真实落在对方仓库） | **571** | **63.5%** |
| ABSENT（对方没有 / 我们没找到） | 328 | 36.5% |
| OWN（只有我方文字描述） | **0** | 0% |
| MIXED | 0 | 0% |

**OWN = 0 是这条纪律的价值所在**：我们没有任何一格用「我方自述」冒充「对方证据」。

**另一半限制（必须一起读）**：`audit-lead` 指出——竞品 133 个「有」格里只有 90 格可核验（67.7%），
其余 **32.3% 仍是我们自己的文字描述**。所以「我们领先」的强度要打折，不能把 REAL 63.5% 当成「对手全核实了」。

**教训**：**REAL 占比高 ≠ 结论强**。要看「对手的格子里有多少是真核验过的」。
