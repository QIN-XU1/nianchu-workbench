# 技能库体检 技能

> 技能越写越多，质量会悄悄滑坡：越写越短、硬约束变稀、塞不可执行的代码块。
> 判据：**每个技能都过「体量/硬约束密度/代码块/重复行/frontmatter」五项检查吗？**

## 什么时候用

- 技能库超过 20 个
- 要评审「技能质量」这类声明
- 发现「新技能越来越水」

## 什么时候**不**用

- 只有几个技能

## 第 1 步：五项体检

| 项 | 判据 |
|---|---|
| 体量 | 超过下限（如 2KB），太短说明没内容 |
| 硬约束密度 | 「必须/不得/禁止/断言」这类词每 KB 的条数 |
| 代码块 | 出现的代码块必须可执行（真路径/真命令），不能是伪代码 |
| 重复行 | 不能大段重复（复制粘贴凑字数） |
| frontmatter | 必填字段齐全 |

## 第 2 步：体量下限 vs 硬约束密度要一起看

只有体量没有硬约束 = 水；只有硬约束太短 = 空喊口号。两者都要过。

## 第 3 步：代码块可执行性

技能里的命令/路径必须能真跑。**伪代码块（`foo()`、`...`）不算**，要删或改成真命令。

## 第 4 步：重复行检测

检测「长行重复」，防止靠复制粘贴凑体量。

## 反例（写下来防复发）

- ✗ 只查体量 → 水技能过检
- ✗ 只查硬约束 → 一句话技能过检
- ✗ 伪代码块当示例 → 读者照抄跑不通
- ✗ 重复行凑字数 → 体量虚高

## 自检清单

- [ ] 五项全查
- [ ] 体量 + 硬约束密度一起看
- [ ] 代码块可执行（无伪代码）
- [ ] 重复行检测

## 参考实现指路

本仓库 `tools/skills/doctor.mjs`（体量/硬约束密度/码块/重复行/frontmatter 五类检查，输出每个技能的 KB 与硬约束密度）；`tools/skills/verify-deep-skills.mjs` 额外验「引用的路径/命令真实存在」。
