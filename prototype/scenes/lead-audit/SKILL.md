# 横向领先审计 技能

> 「我们领先」这个结论，如果只靠自评，就是自我安慰。
> 判据：**对方宣称的每条能力，都落到可执行对照了吗？落后几条？不可核验多少条?**

## 什么时候用

- 要证明「我们领先对手」
- 竞品分析、方案对比
- 要评审「全面领先」这类声明

## 什么时候**不**用

- 无对手可比的内部改进

## 第 1 步：把对方宣称拆成可执行对照

不是「对方说它有 X」就算有——要拆成「X 落到哪个可执行对照（跑什么命令能看到）」。拆不开的 → **不可核验**。

## 第 2 步：三分类逐条计数

- 领先：我们有、对方拆不开或没有
- 落后：对方有、我们没有
- 不可核验：对方宣称但拆不开

报告要给 **领先 N / 落后 M** 与 **不可核验占比**。

## 第 3 步：承认自评的局限（关键）

- 审计是「我方口径」，不是客观评测
- 若不可核验占比高（如 32%），**结论强度要打折**
- 列出限制（如「对方运行时未实测」「口径由我方定」）

## 第 4 步：口径要说清

「净胜」和「零落后」是不同结论。**净胜为正，仍可能某一维落后**——审计要分别给。

## 反例（写下来防复发）

- ✗ 「对方宣称有」直接算对方有 → 无法核验当已知
- ✗ 只报领先不报落后 → 掩盖短板
- ✗ 不承认自评局限 → 把自评当客观
- ✗ 用净胜掩盖单维落后 → 虚假全面领先

## 自检清单

- [ ] 对方宣称拆成可执行对照
- [ ] 领先/落后/不可核验 三分类计数
- [ ] 承认自评局限，给不可核验占比
- [ ] 净胜与零落后分开报
