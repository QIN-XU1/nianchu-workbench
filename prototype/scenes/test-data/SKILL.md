# 测试数据管理 技能

> 测试数据的问题：**用生产数据（隐私风险）、测试互相污染（顺序依赖）、不可复现（偶发失败）**。
> 判据：**这个测试单独跑和全部跑，结果一样吗？用的是不是假数据？**

## 什么时候用

- 写集成/端到端测试
- 测试数据互相污染
- 需要真实感数据

## 什么时候**不**用

- 纯单元测试（构造简单）

## 第 1 步：不能直接用生产数据

| 风险 | 说明 |
|---|---|
| **隐私违法** | 个人信息进测试环境（见 `data-compliance`） |
| 数据不可控 | 生产数据变来变去 |
| 敏感泄露 | 测试环境权限松 |

★ 要用真实感数据，用**脱敏**或**合成**数据。

## 第 2 步：数据构造

| 方式 | 说明 |
|---|---|
| 工厂/fixture | 代码构造（可复现） |
| 合成生成 | 假数据（faker） |
| 快照 | 固定数据集 |
| 脱敏生产数据 | 真实但去标识 |

## 第 3 步：隔离（防污染）

| 手段 | 说明 |
|---|---|
| 每测试自建数据 | 不依赖预置 |
| **事务回滚** | 测试后回滚 |
| 独立库/schema | 隔离 |
| 唯一前缀 | 数据带测试标识 |

⛔ 测试依赖「数据库里已有那条数据」= 顺序依赖 = 单独跑就挂。

## 第 4 步：可复现

| 项 | 要求 |
|---|---|
| 固定种子 | 随机数据可复现 |
| 时间/时区固定 | 见 `timezone-handling` |
| 不依赖外部 | mock 外部依赖 |

## 第 5 步：清理

| 项 | 要求 |
|---|---|
| 测试后清理 | 不留脏数据 |
| 幂等 | 重复跑不累积 |

## 输出格式

**结论**：`四态: PASS | WARN | FAIL | UNKNOWN`
- PASS = 非生产数据 + 隔离 + 可复现 + 清理
- WARN = 有 fixture 但隔离不足
- FAIL = 用生产数据 / 顺序依赖 / 不可复现
- UNKNOWN = 拿不到测试设置

**1. 数据来源**
| 项 | 方式 |
|---|---|

**2. 隔离**
| 手段 | 有吗 |
|---|---|

**3. 可复现**
| 项 | 有吗 |
|---|---|

**4. 判不了的部分**
- <拿不到的测试环境>

## 假阳性清单（这些不算「测试数据好」）

- 用生产数据
- 测试顺序依赖
- 不可复现

## 假阴性清单（最常漏的 8 类）

1. **用生产数据**（隐私违法）
2. **测试顺序依赖**（单独跑挂）
3. **不清理**（脏数据累积）
4. **随机不可复现**
5. **时间/时区不定**
6. **依赖外部服务**
7. **无隔离**（并行冲突）
8. **脱敏不彻底**

## 与其他技能的关系

- `test-strategy`：测试策略
- `test-writing`：写测试
- `data-compliance`：隐私
- `data-retention`：清理

## 边界（如实说清）

- 合成数据可能缺真实分布的边缘
- 脱敏有还原风险
- 本技能不实现，只设计
