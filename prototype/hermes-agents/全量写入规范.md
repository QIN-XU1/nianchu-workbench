# 全量写入规范（12 智能体 → hermes profiles）

> 2026-11-14 定。所有子智能体必须严格照此执行。
> 违反任何一条 = 返工。

## 零、绝对红线

1. **不许碰 hermes 自己的东西**
   - 不修改 `profiles\default\`（hermes 默认 profile）
   - 不修改 `C:\hermes\` 里的任何源码
   - 只允许写 `%LOCALAPPDATA%\hermes\profiles\<你的场景id>\`

2. **中文一律走文件写入，不许走命令行参数**
   - PowerShell 传中文参数会导致显示乱码（实测；文件字节其实是对的，但不可靠）
   - 所有中文内容用 `write` 工具直接写文件（UTF-8）

3. **读文件必须指定 UTF-8**
   - `Get-Content -Encoding UTF8` 或 node `fs.readFileSync(p,'utf8')`
   - 不指定会显示成 `璋冪爺` 这种乱码，让你误判

4. **不许留半成品**
   - 每个场景四层必须全写完：`profile.yaml` / `SOUL.md` / `skills/` / `memories/`
   - 写完必须自验，给出数字证据

## 一、目标映射

| 我们的场景 | hermes 智能体 |

| `外壳/scenarios/<id>.json` | `%LOCALAPPDATA%\hermes\profiles\<id>\` |

| `数据/.dsh/场景记忆/<中文名>/*.md`（除 AGENTS.local.md） | `<profile>\memories\` |

## 二、四层怎么写

### 层 1：profile.yaml（契约）

profile 应已由 `hermes profile create` 建好。**不要重建**，只改 `description`。

写入方式：用 node 脚本读写文件（UTF-8 安全），不要用 CLI 参数。

```js
// description 必须是「合同」：做什么 / 产出什么 / 越界 / 怎么验收
const desc = '职责：<一句话>。产出：<产物名> 给 <下游场景>。越界：<不做什么>。验收：<怎么判定做对了>。';
```

格式要求（这是「合同协作」的基础，下游靠它判断该不该等我）：
- 必须含 **产出**（产物 id + 下游场景名）
- 必须含 **越界**（明确写「不做 X」）
- 必须含 **验收**（可执行的判定，不是形容词）
- 中文，单行，≤200 字

### 层 2：SOUL.md（身份）

**保留 hermes 原有默认 SOUL 的第一段**（那是 Nous 的人格基线，属于 hermes，不动），
在后面追加我们的场景身份。

结构：
```markdown
<hermes 原有默认 SOUL 段落，原样保留>

---

## 我是谁
我是「<场景中文名>」。<一句话职责>

## 我做什么
- <动作 1>
- <动作 2>

## 我不做什么（越界即拒）
- <不该我做的 1>
- <不该我做的 2>

## 硬约束
- <必须遵守的 1>
- <必须遵守的 2>

## 我的偏好
- 用中文回答
- 只记实质结论，不记过程流水账
- 场景自己的记忆自己写
```

来源：`数据/.dsh/场景记忆/<中文名>/AGENTS.local.md` 的「职责」「不碰什么」「场景铁律」「我的偏好（六类）」段。

### 层 3：skills/<id>/（技能）

从 `数据/.dsh/skills/<id>/` 整目录复制到 `<profile>\skills\<id>\`。
保留原有文件名（通常 `SKILL.md` + `check.mjs`）。

### 层 4：memories/（记忆）

从 `数据/.dsh/场景记忆/<中文名>/` 复制**除 `AGENTS.local.md` 外**的所有 `.md`。
保留原文件名。

## 三、验收（每层都要验，给数字）

```powershell
$p = "$env:LOCALAPPDATA\hermes\profiles\<id>"

# ① profile.yaml 的 description 含三项
node -e "const fs=require('fs');const c=fs.readFileSync(process.argv[1],'utf8');const d=(c.match(/^description: (.*)$/m)||[])[1]||'';console.log('len='+d.length+' 产出:'+/产出/.test(d)+' 越界:'+/越界/.test(d)+' 验收:'+/验收/.test(d));" "$p\profile.yaml"

# ② SOUL.md 行数与含关键词
# 必须有：我是谁 / 我做什么 / 我不做什么 / 硬约束

# ③ skills/<id>/ 文件数 与源一致
# ④ memories/ 文件数 与源一致（源数 = 场景目录 .md 总数 - 1）
```

**判定标准：四项全绿才算完成。任何一项数字对不上就是没做完。**
