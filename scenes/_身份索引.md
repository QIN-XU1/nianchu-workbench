## 开场四步（每次新会话必做）

```
① 拿自己的会话 id
② 在本表里查这个 id  →  得到：场景 / 定位卡 / 主技能 / 场景记忆
③ 读定位卡（职责 / 资产 / 触发词 / 铁律 / 上次进度）
④ 读场景记忆的 §〇（进度 / 下一步 / 卡点）
        ↓
     四步做完再动手
```

> 为什么不能靠「在开场消息里写你是 XX 场景」：能用，但换会话/分叉时容易漏，
> 而且面板那边改了它不知道。**表是数据、卡是职责，两者都不在会话里。**
