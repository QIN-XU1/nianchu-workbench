**重要观察**：小云雀的「画布」是**输入卡上的一个开关**，不是独立页面。
打开它只影响「提交后生成到哪里」。要真正进入画布内页，必须**真的发一次生成请求**。

## 三、我们做了什么（浅色反转）

本软件界面是白的，两家都是暗色优先，所以做同一套系统的**浅色反转**：

| 暗色（实测） | 浅色（本项目） |
|---|---|
| base `#000` | `#FFFFFF` |
| 面色 `white 4/6/8%` | `black 3/5/7%` |
| 边框 `#ffffff1f`（12%） | `rgba(0,0,0,.10)` |
| 文字 `#FFF / .7 / .5 / .4` | `#1D2129 / .70 / .60 / .40` |

圆角与字号**直接沿用实测**：卡片 16px、输入框 32px、正文 14px、次级 13px、小字 12px。
主色沿用实测 `#945EFF`。
