# 念初 · 对话面板界面与交互设计拆解（2026-11-22）

> 对象：`apps/vouch-web` 右侧「念初」主 agent 面板（`app/layout/NianchuChat.tsx`）
> 证据：本目录 `evidence/improve-actions-*.png`（1422×804 实机截图，host 120 方法在线）
> 方法：逐像素读图 → 文本清单 → 间距/字号反推 → 与主流 agent 面板（Claude / ChatGPT / Cursor）对照 → 出改进规格

## 1. 现状拆解

### 1.1 布局骨架（自上而下）

| 区域 | 高度 | 内容 | 备注 |
|---|---|---|---|
| 头部 `.ncc__head` | 约 52px | 紫色方形头像「念」+ 标题「念初」+ 右侧 `＋`（新对话）/ `×`（关闭） | 无会话名/无模型/无状态点 |
| 状态条 | 约 26px | 一行小字「插件状态 宿主 120 个方法 · 插件 v1 · 免构建加载」 | **调试信息常驻**，属于开发期文案 |

| 用量脚注 `.ncc__usage` | 约 24px | 「本轮 in 77 / out 89 · 累计 166 tokens」，右对齐 11px | 与元信息的 `in/out` **重复** |

### 1.3 交互逻辑现状

- **发送**：`Enter` 发送、`Shift+Enter` 换行；`busy` 时发送键 disabled。
- **弹层**：输入 `@` / `/` 触发 sug 列表，`↑↓` 选择、`Enter` 填入、`Esc` 关闭；`/` 面板显示总数与「仅示前 50」。
- **消息操作**：悬停显现；复制走 `navigator.clipboard` 并在按钮上回执「已复制」1.2s（`writeText` 被拒时回退 `execCommand`）；重新生成会截断到该助手消息之前并真调一次模型；编辑重发把该条用户消息回填输入框并截断其后。
- **滚动**：`scroll-behavior: smooth`，新消息追加后滚动到底部。

## 2. 问题清单（按严重度）

| # | 级别 | 问题 | 影响 | 位置 |
|---|---|---|---|---|
| 1 | P0 | 状态条常驻「宿主 120 个方法 · 插件 v1 · 免构建加载」 | 调试信息泄漏到产品界面，是「像 demo 不像产品」的主要来源 | 头部下方 |
| 2 | P0 | 无会话历史入口 | 关掉面板/刷新后只能靠「新对话」从零开始；无法回到旧会话 | 头部 |
| 3 | P1 | 元信息与脚注**重复**统计 in/out | 同一数字出现两次，视觉噪音 | 消息元信息 + 脚注 |
| 4 | P1 | 模型名 `auto-claude-sonnet-5-5` 未映射展示名 | 技术串外露，识别成本高 | 助手元信息 |
| 5 | P1 | 无消息级复制之外的操作 | 缺少「赞同/反对」「分支」「删除」等（ChatGPT/Claude 有） | 工具栏 |
| 6 | P2 | 头像/品牌色与全局设计系统不一致 | 面板用 `#7c3aed` 紫，与设置页青绿 `#2D7D6A` 不统一 | 头部 |
| 7 | P2 | 空态无引导 | 新会话只有输入框，没有起手胶囊（已实现但需确认可见性） | 空态 |
| 8 | P2 | 无「停止生成」 | 长回答只能等；`busy` 时发送键只是 disabled | 发送键 |
| 9 | P2 | 输入框无附件/图片/文件入口 | 与 Cursor/Claude 的 `@文件` 拖拽能力不对等 | 输入区 |
| 10 | P3 | 悬停工具栏无过渡曲线细节 | 目前 120ms ease，可接受；按钮无 focus-visible 环 | 工具栏 |

## 3. 改进方案

### 3.1 信息层级（P0）

1. **状态条降级**：把「插件状态…」收进头部右侧一个 `⋯` 菜单（`标题 / 调试信息` 两项），默认隐藏；面板宽度 < 420px 时连同标题截断。
2. **头部重排**：`[头像] 念初 · 当前会话名（可点击切换）  [⏱ 历史] [＋ 新对话] [×]`。会话名未命名时显示「新对话」。
3. **元信息合并**：助手消息底部只保留 `模型展示名 · 77/89 tokens`；删除输入区脚注的「本轮 in/out」，只保留「累计 N tokens」用于会话级感知（或整体改为会话头部的用量徽标）。

### 3.2 交互（P1）

- **消息操作**：助手侧 `复制 / 重新生成 / 分支`；用户侧 `复制 / 编辑重发 / 删除`。「分支」= 从该条之后新建会话树（需 host 支持 `create_session_branch`，暂缺则先隐藏）。
- **停止生成**：`busy` 时发送键切换为 `■` 停止，调用 `interrupt_dialog_turn`（host 侧已有 `stop` 能力，需确认方法名）。
- **键盘**：`Ctrl/Cmd+K` 打开历史会话；`Alt+↑/↓` 在消息间跳转。

### 3.3 视觉（P2）

| 令牌 | 现状 | 建议 |
|---|---|---|
| 品牌色 | `#7c3aed`（紫） | 统一到设置页青绿 `#2D7D6A`，渐变 `#2D7D6A → #4FB39B` |
| 头像圆角 | 8px | 10px（与 `--openbitfun-radius-md` 对齐） |
| 助手左线 | `rgba(148,94,255,.28)` 2px | `rgba(45,125,106,.28)` 2px |
| 用户气泡 | `#f1eaff` / `#2b1d47` | `#EAF6F2` / `#173B33` |
| 消息间距 | 14px | 16px（1280+ 宽度）、12px（< 720px） |
| 元信息字号 | `--openbitfun-type-meta-font-size` | 保持，颜色提到 `rgba(29,33,41,.5)` 以过 WCAG AA |

### 3.4 组件契约（不改 host 契约，仅前端）

```ts
type Msg = {
  id: string;
  role: 'user' | 'assistant' | 'system';
  content: string;
  state?: string;              // 四态透传
  model?: string;              // 原始 id
  modelLabel?: string;         // 展示名（新增，由 model 映射）
  usage?: { prompt_tokens?: number; completion_tokens?: number } | null;
  createdAt?: number;          // 新增：用于时间显示与分组
};
```

工具栏状态：`idle → copied(1.2s) → idle`；`regenerating` 时禁用全部操作按钮并显示骨架条。
