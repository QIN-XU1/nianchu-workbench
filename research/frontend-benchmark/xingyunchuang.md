## 2. 界面结构（按 chunk 与文案推断，非截图）

`index.html` 直接 `modulepreload` 了 `app-canvas / app-flows / app-chat` 三块 —— 说明它是**多主场景**应用：

- **画布（canvas）**：节点式生成。文案证据：「节点」出现 9 次、「添加节点/基础节点/添加下游节点/删除连线/节点端口/导出画布/应用到画布/已入画布/返回画布」。
- **工作流（flows）**：可视化编排。「工作流编辑/编辑子工作流/服务端工作流/运行记录/执行中…/运行环境待同步/把粗提示词优化为可执行生成提示词」。
- **对话（chat）**：「请输入模板标题/模板描述」「获取项目对话产物历史失败」「输入提示词直接生成图片/视频」。

## 3. 功能设计亮点（对念初有借鉴意义的）

1. **节点 + 工作流 + 对话三合一**：生成类任务既能在画布里拖节点（像素级控制），也能在对话里一句话出图，还能把流程存成「服务端工作流」复用。念初目前只有「对话 + 计划图层」，**没有可视化生成画布/工作流编排**（不同产品定位，但「把复杂流程固化成可复用模板」这点可借鉴）。
2. **模型按能力分槽**：「未找到可用图片模型：请先在系统模型管理中启用 image 模型」「默认生图模型 / 默认视频模型 / 默认视频模型」。把「模型」按 image/video/chat 能力分开管理 —— 念初只有一个模型选择，没有能力分槽。
3. **网页账号池 / Cookie / 额度 / 代理**（星云创的独门路线）：「管理 Dola 网页账号池、Cookie、额度和代理」「额度耗尽」「新用户通过 GitHub/手机号注册赠送 100 积分」「Seedance 2.5（会员最长 30 秒）」——它不走官方 API，而是**驱动 dola.com / 豆包 的网页额度**（桌面环境 + Cookie + 代理）。这是灰产边缘路线，**念初不做**（合规与稳定性都不该学），但记录其存在以免误判为「能力更强」。
4. **积分/会员商业化**：额度耗尽、套餐、会员时长上限（30 秒）—— 念初无商业化额度层，属产品定位差异。

## 6. 复算脚本（抽取逻辑）

见仓库根 `.tmp-xyc.cjs`（一次性脚本，未入库）。核心：读 `web-dist/assets/app-{canvas,flows,chat}-*.js`，用
`/(['"\`])((?:\\.|(?!\1)[^\\])*?)\1/g` 抽字符串字面量 → 过滤含中文、长度 2–60、剔除代码符号 → 去重计数 → 按
`对话/画布/流程/模型/设置/错误/积分` 关键词分组抽样。改一行关键词即可复算任一主题。
